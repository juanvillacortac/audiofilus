常见问题

常见问题的快速解答。

关闭应用后音乐就停了。

使用 转到后台（正在播放界面的“更多”菜单，或 设置 → 退出）来关闭播放器并保留音乐。用其他方式关闭（PortMaster 的 SELECT+START、关闭窗口）时，只有开启了 设置 → 关闭后继续播放 才会保留音乐；该设置在掌机上默认关闭，在桌面上默认开启。退出 总是会停止一切。

玩游戏时怎么切歌？

按三下 FN，然后按 L1/R1（上一首/下一首）、L2/R2（快退/快进 10 秒）或 SELECT（暂停）。耳机按键也可以用。

我的设置和数据在哪里？

在程序旁边：audiofilus.json 存放设置，data/ 文件夹存放其他所有内容（音乐库缓存、歌单、历史、歌词、播客、日志）。参见文件存放位置。

怎么更新？

用安装旧版本的方式安装新版本即可。设置和数据会保留，因为它们存放在程序旁边。在 Linux 上，再运行一次安装命令。

在 muOS 上，应该用 PortMaster 版还是 muOS 应用？

两者功能相同。.muxapp 通过 muOS 的 Archive Manager 安装，出现在“应用程序”下；PortMaster 版出现在 Ports 下。它们的设置和数据是分开的。

支持哪些格式？

MP3、AAC/M4A、ALAC、FLAC、Ogg Vorbis、Opus、WAV、AIFF、DSD、tracker 模块（MOD、XM、IT、S3M）、游戏音乐（NSF、SPC、GBS、VGM…）、M3U 播放列表和 CUE 文件。参见格式。

我的 NSF/SPC/VGM 文件无法播放。

游戏音乐需要 libgme，PortMaster 版、muOS 应用和 Linux 下载包都已自带。如果你只复制了程序本身，请把 libs.aarch64（或 libs.x86_64）文件夹也复制到它旁边。在 Linux 桌面上，也可以安装发行版自带的 libgme 软件包。Windows 上暂不支持。

YouTube Music 没有出现。

需要把你自己的 yt-dlp 放进应用的 yt-dlp 文件夹。参见 YouTube Music。

找不到歌词。

检查 设置 → 网上歌词 是否开启，以及设备是否联网。LRCLIB 并没有收录所有歌曲；你可以在歌曲旁边放一个同名的 .lrc 文件，或在 歌词 → START → 选择歌词 中挑选其他版本。没有搜到结果的歌曲会在一周后重试。

歌词快了或慢了。

在歌词视图中，↑/↓ 每次调整半秒；偏移量会为这首歌保存。

Last.fm 提示“API key missing”。

你的构建版本不包含 audiofilus 的 Last.fm 应用密钥。官方发布版包含该密钥；请下载最新版本。

某个电台无法播放。

audiofilus 支持 MP3 和 AAC 电台。不支持 HLS 流（以 .m3u8 结尾并分段的地址）。地址是 .pls 或 .m3u 的电台会被跟随到实际的流。

可以添加自己的电台吗？

可以：把 .m3u/.pls 列表放进应用的 radio 文件夹（它们会出现在 电台 → 我的列表 中），或在“收藏”或“我的列表”中使用 START → 通过地址添加。

电量显示不对。

audiofilus 读取系统的电池信息。有些掌机的电量计总是报告 0 %（比如运行 dArkOS 的 RG353V）；这时 audiofilus 会根据电荷量或电压估算电量，无法估算时则隐藏。

在 dArkOS 上找不到应用的文件夹。

如果你的游戏在第二张 SD 卡上，ports 位于 /roms2/ports 而不是 /roms/ports，因此日志在 /roms2/ports/audiofilus/data/audiofilus.log。

按电源键没有让掌机休眠。

播放器打开时，电源键的作用是让 audiofilus 进入睡眠（关屏，音乐继续），而不是让掌机休眠。转到后台之后，它会像平常一样休眠。在使用“伪休眠”的 ROCKNIX 上，参见 ROCKNIX。

它耗电多吗？

很少：在 RG34XX-SP 上，熄屏方式约 260 mA，大约能放 11 到 12 小时音乐。可视化效果和均衡器耗电更多；关屏时不会绘制任何内容。

怎么在 iPhone 上安装？

从最新版本下载 audiofilus-ios-unsigned.ipa，用 Sideloadly 或 AltStore 安装，它们会用你自己的 Apple ID 签名。也可以把源 https://juanvillacortac.github.io/audiofilus/altstore.json 添加到 AltStore、SideStore 或 LiveContainer：新版本会以更新的形式出现。

怎么在 iPhone 上添加音乐？

在“文件”应用中把歌曲复制到 我的 iPhone → Audiofilus，在 设置 → 文件夹 中选择任意文件夹，或从“文件”和其他应用中用 Audiofilus 打开歌曲。服务器、电台和播客无需本地音乐即可使用。

怎么从文件管理器打开文件？

在 Linux 上，右键 → 打开方式 → Audiofilus（需先用安装脚本或 audiofilus desktop install 安装）。在 Windows 上，audiofilus 首次运行时会自动注册：使用“打开方式”，或在文件夹上使用“用 Audiofilus 播放”。它们会作为临时队列播放。

服务器上的歌曲没有网络能用吗？

曲目目录会被保存，因此可以离线浏览，已播放过的歌曲会被缓存（默认 400 MB）。没有缓存的歌曲需要连接服务器。把歌曲下载到音乐库即可永久保留。

audiofilus 会向网络发送什么？

只发送你用到的：radio-browser（电台界面）、Apple 的播客目录和 RSS 订阅（播客）、LRCLIB（歌词，除非关闭网上歌词）、你自己的服务器、通过你的 yt-dlp 访问的 YouTube，以及仅在你连接后才使用的 Last.fm 或 ListenBrainz。

可视化效果会随 tracker 律动吗？

会。tracker 播放时，可视化效果、跟随节拍的游戏和背景都会跟着它的音乐变化。
