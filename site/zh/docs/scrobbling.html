播放记录

在 Last.fm 和 ListenBrainz 上记录你听过的歌。

设置 → 播放记录 中包含两个账号。时长至少 30 秒的歌曲播放过半（或满四分钟）即算一次；开始播放几秒后会发送“正在播放”。由服务负责发送，所以播放器关闭时也有效。电台和播客单集不会被记录。

Last.fm

  1. 选择 Last.fm。会出现一个指向 Last.fm 授权页面的二维码。
  2. 用手机扫码，并用你的 Last.fm 账号授权 audiofilus。
  3. 几秒钟内 audiofilus 就会显示已以你的用户身份连接。

再次选择即可断开连接。如果提示 缺少 API 密钥，说明你的构建版本不包含 audiofilus 的 Last.fm 应用密钥；官方发布版包含该密钥。

ListenBrainz

选择 ListenBrainz 并输入你的用户令牌（在 ListenBrainz 设置页面中获取）。audiofilus 会验证它并显示你的用户名。

没有网络时

无法发送的收听记录会排队等待，联网后再发送（每隔几分钟重试一次）。令牌错误或会话被撤销时，记录会被丢弃而不是重试。

在你的服务器上

来自 Subsonic 或 Jellyfin 服务器的歌曲也会计入该服务器，除非你关闭 在服务器上计数。
