播放音乐

正在播放、队列、睡眠定时，以及音乐如何在后台继续播放。

正在播放

  • A 或 Y 暂停和继续。
  • 轻按 ←/→ 切换上一首或下一首；按住则快退或快进。L1/R1 也能切歌，L2/R2 快退/快进 10 秒。
  • X 开关随机播放；按两下 X 随机播放一首。
  • ↑/↓ 搓碟。
  • B 进入音乐库，START 打开“更多”菜单。

“更多”菜单包含专辑和艺人、歌词、喜欢、评分、睡眠定时、加入歌单、把队列存为歌单、队列、随机播放、循环（关、全部、单曲）、关闭屏幕、转到后台和退出。

播放队列

队列 界面显示接下来要播放的内容。下一首播放 把歌曲放在当前歌曲之后；加入队列 把它放到末尾。播放无缝衔接，暂停时淡出，队列和播放位置在重启后依然保留。

睡眠定时

正在播放 → 更多 → 睡眠定时。每按一次 A 切换到下一个选项：15、30、45、60 或 90 分钟、播完这首，或关闭。封面上会显示一个月亮和剩余分钟数。定时由服务负责，所以播放器关闭时也有效。

后台播放

音乐运行在独立的服务中；播放器只是一个遥控器。关闭方式决定了音乐会怎样：

  • 转到后台（“更多”菜单，或 设置 → 退出）：播放器关闭，音乐继续播放，在游戏中也一样。掌机会像平常一样休眠。
  • 退出：停止一切。
  • 用其他方式关闭（关闭窗口、PortMaster 的 SELECT+START，或程序崩溃）时，取决于 设置 → 关闭后继续播放：桌面上默认开启，掌机上默认关闭。

在游戏中控制

连按三下 FN，然后在 1.5 秒内：

然后作用
L1 / R1上一首 / 下一首
L2 / R2后退 / 前进 10 秒
SELECT暂停 / 继续

无论播放器打开还是关闭，它始终有效，而且不会与系统或模拟器冲突。

睡眠：关屏，音乐继续

睡眠会在音乐播放时关闭屏幕并降低 CPU 频率，让掌机可以放进口袋。进入方式：按两下 START、按电源键、合上翻盖、正在播放 → 更多 → 关闭屏幕，或者一段时间不操作后自动进入（设置 → 自动熄屏）。睡眠时，肩键变成手势：

手势作用
L1/R1 按两下上一首 / 下一首
L2/R2 按两下后退 / 前进 10 秒
L1+L2 同时按两下暂停 / 继续
R1+R2 同时按两下随机一首
START 或电源键唤醒（合上翻盖时电源键无效）

单按一次不会有反应，所以口袋里的误触不算数。在带振动马达的设备上，每个手势都会有短促的振动反馈。在 RG34XX-SP 上，睡眠时约 260 mA：大约能放 11 到 12 小时音乐。

在桌面上，睡眠及其设置不适用，因此会被隐藏。

耳机按键

蓝牙和有线耳机的按键在播放器打开或关闭时都能控制音乐。单键耳机遵循常见约定：按一下暂停，按两下下一首，按三下上一首。

从文件管理器打开文件

用 audiofilus 打开的文件和文件夹会作为临时队列播放：文件夹会展开其中的所有内容，不会保存为歌单（使用 把队列存为歌单 即可保留）。如果播放器已经打开，它会直接切换到新队列。

  • Linux：右键 → 打开方式 → Audiofilus，适用于音频文件、M3U/PLS 列表、CUE 文件、游戏音乐和文件夹（由安装脚本或 audiofilus desktop install 设置）。
  • Windows：audiofilus 首次打开时会自动注册：所有支持的文件都有 打开方式，文件夹上有 用 Audiofilus 播放。选中多个文件会把它们全部加入队列。
  • iPhone 和 iPad：从“文件”和其他应用中使用“在…中打开”或“共享”。

在桌面上

  • 媒体键和状态栏：在 Linux 上 audiofilus 支持 MPRIS，因此媒体键和桌面的媒体小部件都能控制它。
  • 系统托盘（Linux 和 Windows）：单击打开播放器，中键单击暂停，菜单中有正在播放的内容、播放/暂停、下一首、上一首、随机播放和退出。
