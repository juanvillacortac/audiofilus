音质

ReplayGain、均衡器、淡入淡出和输出采样率。它们由服务应用，所以播放器关闭时也有效。

它们都在 设置 中：淡入淡出在“播放”下，其余在“音质”下。

ReplayGain

使用文件中的 ReplayGain 标签（以及 Opus 的 R128 增益），让每首歌（或每张专辑）以相同响度播放。设置 → ReplayGain：

  • 自动：按顺序播放时按专辑，随机播放时按歌曲。
  • 按歌曲 或 按专辑。
  • 关。

它绝不会把歌曲推过峰值，所以不会削波。没有 ReplayGain 标签的歌曲（以及远程歌曲）按原样播放。

计算 ReplayGain

对于没有 ReplayGain 标签的歌曲，歌曲、专辑或艺人菜单里的计算 ReplayGain 会测量响度（EBU R128，即 ReplayGain 2.0 的方式）并把标签写入文件：按歌曲写，对专辑操作时还会写整张专辑的值。它在后台运行（见下载）；在掌机上每首歌要几秒钟。已经有 ReplayGain 的歌会跳过；重新计算 ReplayGain 会重新测量。适用于你自己音乐库中的 MP3、FLAC、Ogg、Opus 和 M4A。

均衡器

设置 → 均衡器会问你用哪一种：图形 (10段)或参数（见下文）。图形均衡器有从 31 Hz 到 16 kHz 的十个频段，每个范围为 −12 到 +12 dB。

按键作用
←/→选择频段
↑/↓调整 1 dB
X, L1/R1切换预设：平直、低音、高音、人声、摇滚、金属、流行、电子、爵士、古典、响度
Y恢复平直
A / B关闭（调整即时生效）

自己调整频段后，预设会变为 自定义。在触摸屏上，点按某一列即可设置其高度。开启均衡器时，十个频段在掌机最低频率下约占 5 % 的 CPU；保持平直时完全不占用。

参数均衡器

最多八个由你自己塑形的频段，上方会画出曲线。每个频段有类型（峰值、低架、高架、低通或高通）、频率（20 Hz 到 20 kHz）、增益（±15 dB；通滤波器不用它）和 Q（0.3 宽，10 窄）。第一行是前级增益，为提升留出余量。

按键作用
↑/↓选择一行（前级增益或某个频段）
←/→选择字段：类型、频率、增益、Q
A + ↑/↓修改（L1/R1：大步调整）
X / Y添加频段 / 删除所选频段
B / START关闭（改动即时生效）

限幅器仍会防止削波。切回图形均衡器时，参数频段会保留下来以后再用。

重采样

采样率与输出不同的歌曲（例如在 48 kHz 输出下播放 44.1 kHz 的文件）会在播放时转换。设置 → 重采样：

  • 省电：简单且非常轻量，最适合掌机。
  • 高质量：高质量滤波器，直到可听范围顶端都很干净，CPU 占用约为五倍（在电脑上仍然很少）。
  • 自动（默认）：桌面上用高质量，掌机上用省电。

从下一首歌开始生效。

淡入淡出

设置 → 淡入淡出：关闭，或歌曲之间重叠 2 到 12 秒。按顺序播放同一专辑的相邻歌曲时不会淡化，因此专辑保持无缝。很短的歌曲和尚未下载完成的服务器歌曲也会跳过淡化。

输出采样率

设置 → 输出采样率：44.1、48、96 或 192 kHz。更改后会重启音频服务，并从原来的位置继续。当文件采样率相同且没有任何处理（音量 100 %、没有 ReplayGain 或均衡器）时，采样会原样输出，不过 PipeWire 或 PulseAudio 仍可能重新采样。iPhone 上不可用。

音量和增益

音量范围为 0 到 200 %。100 % 以内是系统音量；超过后，audiofilus 会借助限幅器提升信号，让响亮的母带不失真。

DSD

可以播放 DSF 和 DFF 文件，会转换为 PCM。DSD64 对掌机来说足够轻量；DSD256 在掌机上可能跟不上。

DSD 无法以“原生”（DoP）方式输出到 DAC：那需要采样一位不差地送到 DAC，而 audiofilus 的输出和其他应用一样，以 PCM 形式经过系统混音器。转换做得很仔细，但它仍然是一次转换。
