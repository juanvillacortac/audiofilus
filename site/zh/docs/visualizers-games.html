可视化与游戏

八种可视化效果和八款游戏，随正在播放的音乐律动。

可视化效果

从屏幕栏打开 可视化。←/→ 切换可视化效果，A 切换其镜头或变体。

名称
Lake随节拍泛起涟漪的像素湖面
Drift漂浮的粒子
Trench在峡谷中飞行
Plasma使用封面颜色的经典等离子效果
Tunnel隧道
波形波形
Bars频谱柱
Ridges层层堆叠的频谱线，像《Unknown Pleasures》的封面

游戏

从屏幕栏打开 游戏。游戏会随正在播放的音乐节拍进行，包括 tracker 的歌曲。在所有游戏中 START 都是暂停。

游戏玩法
Crypt节奏 Roguelike：在随机生成的地牢中移动和战斗，但只能踩在节拍上。走向敌人即发起攻击。连续踩准节拍会提升倍率，最高 FEVER ×4。使用触控时，点按英雄的某一侧即可向那边移动。
Blocks方块下落游戏，在节拍上硬降可获得连击。←/→ 移动，↓ 软降，↑ 硬降，A/B 旋转，X 暂存。
Rhythm根据歌曲鼓点生成的音符沿四条轨道落下；在判定线上击中它们。
Runner就像 Chrome 的小恐龙，但跟着节拍：A 跳跃（按住跳得更高），↓ 下蹲。在反拍上起跳可获得 PERFECT。
猜歌名播放音乐库中一首歌的几秒钟，给出四个选项；共十个回合。
Snake按照歌曲节拍的细分移动。
Ships射击游戏，每个八分音符开火一次，低音时弹幕散开。
Duel回合制战斗：尽量在进度条中央出击（正好落在节拍上），然后躲开对手发射的音符。

Tracker 也在“游戏”中。
