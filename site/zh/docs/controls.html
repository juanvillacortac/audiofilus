操作

掌机上的按键、桌面上的键盘，以及触控和鼠标。

在任何界面按住 FN（F1）即可查看该界面的按键。以下按键在所有地方通用：

按键键盘作用
SELECTTab屏幕栏；按两下返回上一个界面
STARTM当前界面的“更多”菜单；快速按两下进入睡眠
YSpace暂停 / 继续
L1 / R1Q / E上一首 / 下一首
L2 / R2, / .后退 / 前进 10 秒
AEnter确认 / 打开
BEsc, Backspace返回
XS随机播放
FNF1按住显示操作指南

在游戏中，START 改为暂停。左摇杆在任何地方都和十字键一样。设置 → 交换 A/B 可以交换确认和返回。

播放器关闭时

参见在游戏中控制（按三下 FN）和睡眠手势。

触控和鼠标

  • 可以点按列表行、封面、标签页、菜单方块、设置方块、播放器按钮和进度条。点按一行即可打开。
  • 列表在手指下带惯性滚动；鼠标滚轮也能滚动。
  • 长按（半秒）相当于 START；右键相当于 B；中键单击暂停。
  • 底部的按键提示可以点按；使用触控时它们会变成带名称的真实按钮。
  • 竖屏时，音乐库、电台和播客的标签页从一个按钮以下拉菜单形式打开。
  • 游戏有各自的触控操作（参见可视化与游戏）。
