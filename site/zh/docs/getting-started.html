入门

在你的设备上安装 audiofilus，打开它，并指定你的音乐文件夹。

使用 PortMaster 的掌机

支持 Knulli、muOS、ROCKNIX、ArkOS 和 dArkOS。

  1. 从最新版本下载 audiofilus-portmaster.zip。
  2. 用 PortMaster 安装，或解压到你的 ports 文件夹。
  3. 在 Ports 中打开 audiofilus。

这个 port 自带所需的一切，包括播放游戏音乐的库（libgme）。

muOS，不用 PortMaster

  1. 从最新版本下载 audiofilus.muxapp。
  2. 把它复制到 SD 卡（或 U 盘）根目录下的 ARCHIVE 文件夹。
  3. 打开 muOS 的 Archive Manager 并安装。audiofilus 会出现在 应用程序 下。

Linux 桌面

curl -fsSL https://juanvillacortac.github.io/audiofilus/install.sh | sh

它会把 audiofilus 安装到 ~/.local/share/audiofilus，把 audiofilus 链接到 ~/.local/bin，并添加到应用启动器（音频文件和文件夹支持“打开方式”）。再运行一次即可更新；你的设置会保留。

手动安装：把 audiofilus-linux-amd64.tar.gz（或 -arm64）解压到任意位置，然后运行一次 ./audiofilus desktop install。

Windows

在 Windows 10 或更高版本上，把 audiofilus-windows-amd64.zip 解压到任意位置并运行 audiofilus.exe。MP3、FLAC、Ogg Vorbis、ALAC、WAV 和 AIFF 开箱即用。若要播放 AAC/M4A、Opus 和 tracker 模块，请把 MSYS2 的 DLL 放到 .exe 旁边：libfdk-aac-2.dll、libopusfile-0.dll（以及 libopus-0.dll 和 libogg-0.dll）、libmpg123-0.dll 和 libxmp-4.dll。Windows 上暂不支持游戏音乐。

iPhone 和 iPad

每个版本都附带未签名的 audiofilus-ios-unsigned.ipa。用 Sideloadly 或 AltStore 安装，它们会用你自己的 Apple ID 签名。

也可以把源 https://juanvillacortac.github.io/audiofilus/altstore.json 添加到 AltStore、SideStore 或 LiveContainer：新版本会以更新的形式出现。

首次运行：选择音乐文件夹

在掌机或桌面上，第一次打开 audiofilus 时会显示文件夹浏览器。A 打开文件夹，B 返回上一级，X 使用当前文件夹。音乐库只完整扫描一次，并显示进度条；之后启动只读取新增或修改过的文件。之后可以在 设置 → 文件夹 中更换文件夹，用 重新扫描 重新扫描。

没有自己的音乐？audiofilus 照样会以空音乐库打开，服务器、电台、播客和 YouTube Music 依然可用。

在 iPhone 上，在“文件”应用中把歌曲复制到 我的 iPhone → Audiofilus，或在 设置 → 文件夹 中选择任意文件夹（iCloud 云盘或其他应用）。

熟悉操作

  • SELECT 打开屏幕栏（正在播放、音乐库、搜索、队列、电台、播客、游戏、设置…）。按两下返回上一个界面。
  • START 打开当前界面的“更多”菜单。
  • 按住 FN（键盘上是 F1）可以查看每个按键在该界面的作用。

更新

用同样的方式安装新版本。你的设置（audiofilus.json）和数据（data/）存放在程序旁边，所以会保留。
