网络

在家里的音箱或电视上播放，让其他设备浏览你的音乐库，或者让手机把音乐发到掌机上。这一切都只在你的局域网内进行。

发送到音箱或电视

在正在播放中，START → 发送到… 会花大约三秒查找网络上的设备并列出来：DLNA/UPnP 音箱和电视，以及 Chromecast（内置 Chromecast 的电视、Google/Nest 音箱）。

  • 选一个设备，歌曲就从同一秒在那里继续播放；掌机或电脑会暂停，变成遥控器。队列里的下一首会提前发过去，所以设备会继续按队列播放。
  • 发送时，顶部栏显示 → <设备>，暂停、下一首、上一首和快进都控制该设备；进度条显示设备的播放位置。
  • START → 设备音量可以调高或调低设备音量。停止发送到 <设备> 会停止设备，并在这里从同一首歌的同一秒继续。
  • Audiofilus 能播放的内容都能发送。MP3、FLAC、AAC/M4A、WAV 和 Ogg 原样发送；模块、游戏机音乐、DSD 和 CUE 曲目会即时转换为 WAV。来自 Subsonic/Jellyfin 服务器的歌曲和电台按各自的地址发送。

共享音乐库（DLNA 服务器）

打开设置 → 共享音乐库 (DLNA)，同一网络里的电视、游戏机和 DLNA 应用就能看到你的音乐库，名称为 <设备名>（电脑的名称，或掌机的型号）。它们可以带封面浏览艺人、专辑、歌曲、歌单和文件夹，并从那里播放。电视不认识的格式会转换成 WAV 给它。共享的是 Audiofilus 已经扫描过的音乐库，服务器上的歌曲不会共享。

接收音乐（DLNA 渲染器）

打开设置 → 接收音乐 (DLNA)，掌机或电脑就成了其他应用的音箱：在手机上的 BubbleUPnP、Windows 的投放到设备或任何 UPnP 控制点里选择 <设备名>，然后发送歌曲。歌曲会带着标题和艺人在 Audiofilus 里播放，播放、暂停、快进和音量由发送的应用控制。每首歌会先下载再播放，所以在 Wi-Fi 上开始前要等一会儿。

MPD

设置 → MPD 服务器让 MPD 应用（ncmpcpp、Cantata、M.A.L.P.、Rigelian、MPDroid 等）和其他 Audiofilus 控制这台设备上的音乐：播放队列、带封面的音乐库、你的播放列表、音量和快进快退。默认关闭。它的菜单会显示要在应用里填写的地址（例如 192.168.1.5:6600），也可以设置密码；会搜索网络的应用能自己找到它。手机应用里没有这个功能。

  • 从另一台 Audiofilus：在正在播放中，START → 发送到… 也会列出开着 MPD 服务器的设备。歌曲在那台设备上无缝衔接，START → <设备> 的音乐库 可以浏览它的专辑并在那里播放。如果设了密码，第一次会询问。
  • 在接收的设备上：其他设备向它发送音乐时，顶部栏显示 ← <地址>，START 里有停止接收（这里的音乐停下，发送的那台 Audiofilus 会自己继续播放）和关闭 MPD 服务器。通过 DLNA 收到的音乐也一样。
  • 接收时重启，会回到你自己的播放队列。

两台 Audiofilus 之间，MPD 更好：无缝衔接、可设密码，还能用对方的音乐库。DLNA 适合电视、音箱和不支持 MPD 的应用。

说明

  • 两个 DLNA 选项默认都是关闭的。关闭时，不会在网络上监听任何东西。
  • 共享和接收本身不会让掌机保持唤醒：掌机休眠后，要等它醒来才会再响应。
  • 电脑上的防火墙需要允许设备连到 Audiofilus（媒体端口每次随机选择）。
  • 在终端里：audiofilus dlna 显示状态，audiofilus dlna server on|off、audiofilus dlna renderer on|off 和 audiofilus dlna name <名称> 可以修改。
  • 在终端里：audiofilus mpd 显示 MPD 服务器的状态，audiofilus mpd on|off、audiofilus mpd password [<密码>]、audiofilus mpd port <端口> 和 audiofilus mpd name <名称> 可以修改。
  • 在 iPhone 和 iPad 上，第一次查找时会请求使用本地网络的权限。
