电台和播客

来自数千个电台或你自己的列表的网络电台，以及支持下载和续播的播客。

电台

从屏幕栏（SELECT）打开 电台。它的标签页：

  • 收藏：你保存的电台（在电台上按 START → 加入收藏）。
  • 我的列表：你自己的电台列表（见下文）。
  • 热门：你所在国家播放最多的电台；X 切换到全球。用菜单中的 国家 更改国家。
  • 搜索：按电台名称搜索（X 或 START 开始搜索）。
  • 类型。

电台来自 radio-browser.info。A 收听；电台播放时，L1/R1 切换到列表中的上一个或下一个电台，电台发送歌名时会实时显示。支持 MP3 和 AAC 电台，不支持 HLS 流。

你自己的电台列表

  • 把 .m3u、.m3u8 或 .pls 电台列表放进应用旁边的 radio 文件夹（在掌机上，位于 port 的文件夹中）。它们会出现在 我的列表 下，并带有文件中的名称和图标。
  • 通过地址添加：在“收藏”或“我的列表”上按 START，输入电台地址和名称，即可保存到收藏。
  • 如果电台地址本身是一个播放列表（比如 listen.pls），audiofilus 会跟随它找到实际的流。

播客

从屏幕栏打开 播客。标签页：已订阅、热门（你所在国家的热门节目）和 搜索。在“已订阅”上按 START 可以通过 RSS 地址添加播客。

  • 在播客上按 A 打开其单集，最新的在前，显示日期、时长，以及你是否已播放、停在哪里或是否已下载。
  • 单集在播放前会先下载（通过“下载”队列），然后从 SD 卡播放。
  • 播放位置会被记住，续播时会提前三秒开始，方便你回到状态。接近结尾时，单集会被标记为已播放。
  • 在单集上按 START：收听、下载或删除下载、标记为已播放或未播放。在播客上：订阅或移除、刷新，以及 自动下载新集。
