audiofilus 文档

关于使用 audiofilus 的一切：安装、熟悉操作，以及每个界面和设置的作用。

audiofilus 是一款音乐播放器，支持 Linux 掌机（Knulli、muOS、ROCKNIX、ArkOS、dArkOS 和 EmuELEC）、Linux 和 Windows 桌面，以及 iPhone 和 iPad。音乐运行在后台服务中，所以关闭播放器或启动游戏后它仍会继续播放。

第一次来？先看入门，然后在任何界面按住 FN 查看按键。

主题

  • 入门在你的设备上安装 audiofilus，打开它，并指定你的音乐文件夹。
  • 音乐库浏览、搜索和整理你的音乐，查看你最近在听什么。
  • 播放正在播放、队列、睡眠定时，以及音乐如何在后台继续播放。
  • 音质ReplayGain、均衡器、淡入淡出和输出采样率。它们由服务应用，所以播放器关闭时也有效。
  • 歌词随演唱上色的同步歌词，来自你的文件或在线查找。
  • 电台和播客来自数千个电台或你自己的列表的网络电台，以及支持下载和续播的播客。
  • 模块来自 The Mod Archive、Modland、VGMRips 和 AMP 的 tracker 模块和游戏机音乐：收听、保存或在 tracker 中打开。
  • 网络把音乐发送到音箱和电视（DLNA 和 Chromecast），共享音乐库，接收手机发来的音乐。
  • 服务器把音乐服务器当作另一个音乐库，支持流媒体、缓存、收藏和播放次数。
  • YouTube Music搜索 YouTube Music，无需下载即可收听，或把歌曲保存到音乐库。需要自备 yt-dlp。
  • 播放记录在 Last.fm 和 ListenBrainz 上记录你听过的歌。
  • 操作掌机上的按键、桌面上的键盘，以及触控和鼠标。
  • 可视化与游戏九种可视化效果和八款游戏，随正在播放的音乐律动。
  • Tracker用十字键以 LSDJ 的方式制作芯片音乐。
  • 设置设置中的每个方块，逐节说明。
  • 掌机系统audiofilus 在 Knulli、muOS、ROCKNIX、ArkOS、dArkOS 和 EmuELEC 上的不同之处。
  • 常见问题常见问题的快速解答。
