歌词

随演唱上色的同步歌词，来自你的文件或在线查找。

打开歌词

在正在播放界面，打开 更多 → 歌词，或点按可视化区域。B 返回。歌词显示时，播放器不会自动进入睡眠。

  • 同步歌词：当前行保持居中，并随着演唱填充颜色。较长的间奏部分会显示三个圆点，逐渐填满直到人声回来。
  • 非同步歌词：随歌曲滚动；↑/↓、手指或滚轮可以手动滚动。

歌词来源

  1. 你手动选择的版本。
  2. 与歌曲同名的 .lrc 文件，放在歌曲旁边或 lyrics 文件夹中。
  3. 文件标签：ID3 SYLT 和 USLT、FLAC 和 Ogg 中的 LYRICS、M4A 中的 ©lyr。
  4. LRCLIB，一个免费的在线歌词数据库（按标题、艺人和时长查找）。
  5. 来自 .txt 或标签的非同步歌词。

在线找到的歌词会被保存，因此每首歌只查找一次。LRCLIB 标记为纯音乐的歌曲会显示 INSTRUMENTAL。

选择其他版本和调整时间

  • START → 选择歌词 会列出所有版本：本地文件、标签、LRCLIB 的每个匹配结果（带专辑和时长），以及 无歌词。你的选择会为这首歌记住。
  • ↑/↓ 让同步歌词提前或推迟 0.5 秒；菜单中的 偏移 可以重置。偏移量按歌曲保存。

电台歌词

以“艺人 - 歌名”格式发送标题的电台也能显示歌词。同步歌词从标题变化时开始计时；电台发送标题常常会晚几秒，可以用 ↑/↓ 微调。

保持离线

关闭 设置 → 网络歌词：只使用你的文件和标签。
