Linux 掌机音乐播放器

边玩游戏，音乐不停。

audiofilus 是一款像素风音乐播放器，带专辑封面、可视化效果、八款街机小游戏和一个芯片音乐编曲器（tracker）。关掉它、打开模拟器，音乐照样继续。关掉屏幕，放在口袋里也能控制。

Knulli · muOS · ROCKNIX · ArkOS · dArkOS —— 也支持 Linux 和 Windows 桌面，以及 iPhone。

后台播放

不碍事的播放器

音频运行在独立的服务中

界面只是一个遥控器。关掉它，音乐继续播放；启动游戏，音乐依旧在响，切歌无缝衔接，暂停时会快速淡出。

在任何游戏里都能控制

按住 FN 再按一个键，即可暂停、下一首、上一首或快进快退。耳机上的播放键也能用，蓝牙或有线都行：按一下暂停，按两下下一首，按三下上一首。

放进口袋的睡眠模式

按两下 START 或电源键：屏幕关闭，CPU 降频，肩键变成手势操作。合上翻盖也会保持睡眠。在 RG34XX-SP 上，这个模式的电流约为 260 mA：3300 mAh 电池大约能放 11 到 12 小时音乐。

帮助只需一个按键

在任何界面按住 FN，就能看到每个按键在这里的作用。

按住 FN 时显示的操作指南。

START 打开“更多”菜单，其中的“后台”可以退出应用并继续收听。

可视化与游戏

有东西可看

八种随节拍律动的可视化效果，全部以低分辨率绘制，对 CPU 很友好。颜色取自专辑封面。

Tracker

做你自己的芯片音乐

一款 LSDJ 风格、用十字键操作的 tracker，带点 PICO-8 的味道：链（chain）与乐句（phrase）、带包络和表（table）的乐器、带摇摆感的律动（groove）、可编辑波形、21 种效果指令和钢琴卷帘。可以为 Game Boy 的四个声道写曲，也可以切到自由模式，用八个合成器声道。把歌曲导出为 WAV，它就会出现在你的曲库里，像其他歌一样在后台播放。Tracker 指南。

游戏和 tracker 都在屏幕栏的 游戏 入口里，每个游戏都有自己的最高纪录。应用里还藏着几个彩蛋。

配色

每张专辑都为它上色

界面的颜色取自正在播放的封面。换一张专辑，整个播放器、可视化效果和游戏都会跟着变色。

以真实曲库中的四张专辑为例：每张封面提供两种强调色和一种背景色调。

歌词

跟着唱

同步歌词会随着演唱逐字上色，间奏部分用圆点倒数。歌词来自歌曲旁的 .lrc 文件、歌曲标签，或在线的 LRCLIB。

可以从列表中选择其他版本，以半秒为单位微调时间，或者只用离线歌词。此动画中的歌词是虚构的。

音质

按你喜欢的方式调音

ReplayGain

每首歌同样响度，或每张专辑同样响度，或自动：按顺序播放时按专辑，随机播放时按单曲。绝不会把歌曲推过峰值。

10 段均衡器

预设有摇滚、金属、人声、低音等，也可以自己调节各个频段。在掌机上大约占用 5 % 的 CPU，保持平直时完全不占用。

交叉淡化、DSD 和 CUE 文件

最长 12 秒的交叉淡化，同时保持专辑无缝播放。支持 DSD 文件；用 CUE 文件整轨抓取的专辑会按曲目显示；输出采样率可选 44.1、48、96 或 192 kHz。

根据你播放过的所有内容生成统计，即使播放器关闭，服务也会照常计数。

红心表示喜欢的歌，月亮显示睡眠定时剩余的分钟数。

你的收听

它记得你听过什么

喜欢的歌和评分

给歌曲点红心或打一到五星。在 Subsonic、Navidrome 或 Jellyfin 服务器上，红心和星级双向同步。

最近播放、最常播放和统计

自动生成的列表，还有你的收听时长、最常听的艺人、专辑和歌曲。

Scrobble 记录

用二维码登录 Last.fm，或粘贴你的 ListenBrainz 令牌。离线时收听记录会先排队，联网后再发送，播放次数也会计入你自己的服务器。

睡眠定时

在 15 到 90 分钟后或当前歌曲结束时停止音乐，即使播放器已关闭。

音源

你的文件、你的服务器、电台

所有内容都出现在同一个曲库和同一个播放器里。远程歌曲会缓存到 SD 卡，下次收听不再耗费流量。

本地

你的曲库

文件夹、标签、内嵌封面和文件夹封面、M3U 播放列表以及你自己的播放列表。只完整扫描一次，之后只读取新文件。同步歌词逐行点亮，来源可以是 .lrc、标签或 LRCLIB。还支持游戏原声：NES、SNES、Game Boy、Genesis 等，每首歌一条曲目。

服务器

Subsonic

Navidrome 以及其他 Subsonic 或 OpenSubsonic 服务器。歌曲以流媒体播放，缓存后下次可直接收听，也可以下载。

服务器

Jellyfin

用你的 Jellyfin 账号登录，像浏览本地文件一样浏览它的音乐库和播放列表。

直播

网络电台

来自 radio-browser.info 的数千个电台，可按国家或流派浏览，并显示流中当前播放的歌名。也可以使用你自己的 .m3u 或 .pls 电台列表，或通过地址添加电台。

单集

播客

你所在国家的热门节目、搜索，或通过地址添加任意 RSS 订阅。单集可下载离线收听，并记住你停在哪里。

自备工具

YouTube Music

把你自己的 yt-dlp 复制到应用旁边，搜索功能就会出现：无需下载即可收听，也可以把歌曲连同封面和标签保存到曲库。

界面

为十字键而生

SELECT 打开包含所有界面的屏幕栏；按两下回到上一个界面。屏幕上的 QWERTY 键盘用于搜索和输入播放列表名称。界面音效可选，菜单和音乐操作各有独立开关。

任意屏幕

从方屏到超宽屏

布局会根据屏幕的实际宽度自适应，而不是从几种固定形状里挑选，所以无论是 1:1 的 RGB30、3:2 的翻盖机还是 21:9 的显示器都能铺满。

安装

通过 PortMaster

KnullimuOSROCKNIXArkOSdArkOS
  1. 从最新版本下载 audiofilus-portmaster.zip。
  2. 用 PortMaster 安装，或解压到你的 ports 文件夹。
  3. 在 Ports 中打开 audiofilus，然后选择你的音乐文件夹。
  4. 可选：把 yt-dlp 程序放进应用的 yt-dlp/ 文件夹，即可启用 YouTube Music。

在 muOS 上可以不用 PortMaster：把 audiofilus.muxapp 复制到 SD 卡的 ARCHIVE 文件夹，然后在 Archive Manager 中安装；它会出现在“应用程序”里。

在 Linux 或 Windows 电脑上，请看桌面版。

启动时会自动识别系统。翻盖、电源键、省电和音量都使用该系统自带的工具；在桌面上这些都会跳过。

从源码构建

一条命令

用 Go 编写，掌机版不使用 cgo。解码库在运行时加载（如果系统中有的话）。

# with Docker, nothing else to install
git clone https://github.com/juanvillacortac/audiofilus
cd audiofilus
docker build --target dist --output dist .

# or with Go installed
./build.sh

两种方式都会在 dist/ 中生成桌面版和 arm64 程序，以及 PortMaster 压缩包。

桌面版

在电脑上也得心应手

同一个播放器可在 Linux 和 Windows 上运行，只是一个小小的程序文件。在 Linux 上，它在 GNOME、KDE、Hyprland 和 Omarchy 中都像原生应用一样。

出现在应用启动器中

Audiofilus 带着自己的图标出现在启动器中，右键可以播放/暂停、下一首和上一首。窗口规则和程序坞都能识别它的窗口。在 Linux 和 Windows 上，都可以从文件管理器用它打开文件和文件夹。

媒体键和状态栏

它支持 MPRIS，因此键盘媒体键、耳机和桌面的媒体小部件都能控制它，并显示封面和歌名。在 Omarchy 上无需任何设置即可使用。

依然可以后台播放

关闭窗口后音乐继续播放（这是一个设置项，桌面版默认开启）；再次打开时会接着当前状态，不显示启动画面。“退出”会停止一切。

在系统托盘中

audiofilus 的 CD 图标会出现在 Linux 和 Windows 的托盘中：单击打开播放器，中键单击暂停，或打开菜单查看正在播放的内容、播放/暂停、下一首、上一首、随机播放和退出。

任意窗口形状

把窗口拉宽，或变得又高又窄：竖屏时会切换为手机风格的播放器，带大封面，像素依然清晰。

Linux

一行命令安装

curl -fsSL https://juanvillacortac.github.io/audiofilus/install.sh | sh
  1. 将适用于 x86_64 或 aarch64 的最新版本下载到 ~/.local/share/audiofilus。
  2. 把 audiofilus 链接到 ~/.local/bin。
  3. 把 Audiofilus 添加到应用启动器。随时再运行一次即可更新；你的设置会保留。

或者手动安装

  1. 从最新版本下载 audiofilus-linux-amd64.tar.gz（或 -arm64），解压到任意位置。
  2. 在该文件夹中运行 ./audiofilus desktop install。它会把启动器条目和图标添加到 ~/.local/share。
  3. 从应用启动器打开 Audiofilus。如果移动了文件夹，请重新执行第 2 步。

卸载：audiofilus quit; audiofilus desktop uninstall; rm -rf ~/.local/share/audiofilus ~/.local/bin/audiofilus*

Windows 10 或更高版本：下载 audiofilus-windows-amd64.zip，解压到任意位置并运行 audiofilus.exe。

iPhone 和 iPad

真正装进口袋

同样的像素播放器来到 iOS，为手指操作而设计：一切都可以点按，列表在拇指下带惯性滚动，锁屏后音乐继续播放。

触控优先

点按行、封面、标签页和按钮；用拇指拖动列表；按键栏是真正的按钮，游戏也有专门的触控操作。竖屏时，标签页从一个按钮展开。

锁屏和控制中心

封面、歌曲和控制按钮出现在锁屏、控制中心、耳机和 CarPlay 中。来自 iTunes 的 AAC 和 AAC 电台通过 Apple 自己的解码器播放。

你的音乐，你做主

在“文件”应用中把歌曲复制到 我的 iPhone → Audiofilus，从 iCloud 云盘选择任意文件夹，或者不用本地音乐，直接收听 Subsonic、Navidrome 或 Jellyfin、电台、播客和 YouTube Music。也可以从“文件”和其他应用中用 Audiofilus 打开歌曲。

每个版本都附带未签名的 audiofilus-ios-unsigned.ipa：用 Sideloadly 或 AltStore 安装，它们会用你自己的 Apple ID 签名。也可以把源 https://juanvillacortac.github.io/audiofilus/altstore.json 添加到 AltStore、SideStore 或 LiveContainer：新版本会以更新的形式出现。
