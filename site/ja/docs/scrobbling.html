スクロブル

聴いた曲を Last.fm と ListenBrainz に記録します。

Settings → Scrobbling に両方のアカウントがあります。30 秒以上の曲で、半分（または 4 分）が再生されると 1 回とカウントされます。「再生中」は再生開始の数秒後に送られます。送信はサービスが行うので、プレイヤーを閉じても動作します。ラジオとポッドキャストのエピソードはスクロブルされません。

Last.fm

  1. Last.fm を選びます。Last.fm の認証ページの QR コードが表示されます。
  2. スマートフォンで読み取り、Last.fm アカウントで audiofilus を承認します。
  3. 数秒で、audiofilus にあなたのユーザー名で接続されたと表示されます。

もう一度選ぶと接続を解除します。API key missing と表示される場合、お使いのビルドには audiofilus の Last.fm アプリケーションキーが含まれていません。公式リリースには含まれています。

ListenBrainz

ListenBrainz を選び、ユーザートークン（ListenBrainz の設定ページにあります）を入力します。audiofilus がそれを確認し、ユーザー名を表示します。

接続がないとき

送信できなかった再生記録は待機し、接続が戻ると送信されます（数分ごとに再試行します）。間違ったトークンや取り消されたセッションの場合は、再試行せずに破棄します。

サーバー側で

Subsonic や Jellyfin のサーバーの曲は、Count on the server をオフにしない限り、そのサーバーでもカウントされます。
