ネットワーク

家のスピーカーやテレビで再生したり、ほかの機器からライブラリを見られるようにしたり、スマホから携帯ゲーム機へ音楽を送ったりできます。どれもローカルネットワークの中だけで完結します。

スピーカーやテレビに送る

再生中で START → 送信先… を選ぶと、約 3 秒ネットワーク上の機器を探して一覧にします。DLNA/UPnP のスピーカーやテレビ、Chromecast（Chromecast 内蔵テレビ、Google/Nest スピーカー）です。

  • 機器を選ぶと、同じ秒から曲がそちらで続きます。携帯ゲーム機やパソコンは一時停止してリモコンになります。キューの次の曲も先に送られるので、機器はそのままキューを進めます。
  • 送信中は上のバーに → <機器> と表示され、一時停止・次へ・前へ・シークは機器を操作します。進行バーは機器の再生位置を示します。
  • START → 機器の音量で機器の音量を上げ下げできます。<機器> への送信をやめるで機器を止め、同じ曲の同じ秒からこちらで再生を続けます。
  • Audiofilus で再生できるものは何でも送れます。MP3、FLAC、AAC/M4A、WAV、Ogg はそのまま送り、モジュール、ゲーム機の音楽、DSD、CUE のトラックはその場で WAV に変換します。Subsonic/Jellyfin サーバーの曲とラジオ局は、それぞれのアドレスで送ります。

ライブラリを共有する（DLNA サーバー）

設定 → ライブラリ共有 (DLNA) をオンにすると、同じネットワークのテレビ、ゲーム機、DLNA アプリにライブラリが Audiofilus (<機器名>) として表示されます。アーティスト、アルバム、曲、プレイリスト、フォルダーをジャケット付きで見て、そこから再生できます。テレビが対応していない形式は WAV に変換して渡します。共有するのは Audiofilus がスキャン済みのライブラリで、サーバーの曲は共有しません。

音楽を受け取る（DLNA レンダラー）

設定 → 音楽を受信 (DLNA) をオンにすると、携帯ゲーム機やパソコンがほかのアプリのスピーカーになります。スマホの BubbleUPnP、Windows のデバイスにキャスト、そのほかの UPnP コントロールポイントから Audiofilus を選んで曲を送ってください。曲はタイトルとアーティスト付きで Audiofilus から鳴り、再生・一時停止・シーク・音量は送った側のアプリで操作します。曲は先にダウンロードしてから再生するので、Wi-Fi では始まるまで少しかかります。

注意

  • DLNA のふたつの設定は初期状態でオフです。オフのときは、ネットワークで何も待ち受けません。
  • 共有や受信が、携帯ゲーム機をスリープさせないようにすることはありません。スリープすると、起きるまで応答しません。
  • パソコンのファイアウォールは、機器が Audiofilus に届くように許可する必要があります（メディア用のポートは毎回ランダムに選ばれます）。
  • ターミナルからは、audiofilus dlna で状態を表示し、audiofilus dlna server on|off、audiofilus dlna renderer on|off、audiofilus dlna name <名前> で変更できます。
  • iPhone と iPad では、最初の検索のときにローカルネットワークの利用許可を求められます。
