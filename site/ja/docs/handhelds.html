携帯ゲーム機

Knulli、muOS、ROCKNIX、ArkOS、dArkOS、EmuELEC で audiofilus が何を変えるか。

audiofilus は起動時にシステムを検出し、ふた、電源ボタン、音量、バッテリーにそのシステム自身の仕組みを使います。Knulli を入れた Anbernic RG34XX-SP でテストしています。

ファイルの場所

設定（audiofilus.json）とデータ（data/：ライブラリのキャッシュ、プレイリスト、履歴、歌詞、ポッドキャスト、ログ audiofilus.log）はプログラムの隣、ポートのフォルダーにあります：

システムフォルダー
Knulli/userdata/roms/ports/audiofilus
ArkOS、dArkOS、EmuELEC/roms/ports/audiofilus、ゲームが 2 枚目の SD カードにある場合は /roms2/ports/audiofilus
EmuELEC/storage/roms/ports/audiofilus
muOS（アプリ）MUOS/application の下のアプリのフォルダー

電源ボタン

  • プレイヤーが開いているとき、電源ボタンを軽く押すと、ゲーム機をスリープさせる代わりに audiofilus がスリープ（画面オフ、音楽オン）します。長押しすれば電源は切れます。
  • バックグラウンドへの後は、押すとゲーム機は通常どおりスリープします。

プレイヤーが開いている間は、システムのアイドル時のスリープと画面の減光も止めます。

Knulli

  • プレイヤーが開いている間、音量ボタンは audiofilus を通るので、100 % を超えて上げられます。
  • ふたを閉じると audiofilus はスリープします。ふたを開けても復帰せず、START で復帰します。

muOS

  • PortMaster か、ネイティブアプリ（audiofilus.muxapp、はじめにを参照）としてインストールします。
  • 100 % を超える音量はアプリ側で上げます。システムの音量は muOS 自身のボタンで操作します。

ROCKNIX

  • ROCKNIX の「疑似サスペンド」（設定でサスペンドモードをオフ）では、電源ボタンを押すとすべてがミュートされて止まり、audiofilus には止められません。通常のサスペンド（デフォルト）では、ボタンで audiofilus がスリープします。

ArkOS と dArkOS

  • バッテリー残量が常に 0 % と表示されるゲーム機（dArkOS の RG353V など）では、残量を充電量か電圧から推定するか、表示しません。

EmuELEC

  • Odroid Go Advance／Super、GameForce Chi、Amlogic の TV ボックスで動作します。実機ではまだ試していません。
  • 携帯ゲーム機では、プレイヤーが開いているとき、電源ボタンはゲーム機をスリープさせずに audiofilus をスリープさせます。TV ボックスはスリープしません。
  • 先に EmuELEC のメニューから PortMaster をインストールしてください。手動でインストールする場合は、Audiofilus.sh を /storage/roms/ports_scripts（EmuELEC がポートを一覧表示する場所）に、audiofilus フォルダーを /storage/roms/ports に置きます。

バッテリーの消費

RG34XX-SP での測定：スリープ中の audiofilus の消費電流は約 260 mA で、3300 mAh のバッテリーで音楽を 11〜12 時間ほど再生できます。
