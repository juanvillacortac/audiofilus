歌詞

歌に合わせて色が変わる同期歌詞。ファイルから、またはオンラインで見つけます。

歌詞を開く

再生中でその他 → 歌詞を開くか、ビジュアライザーをタップします。B で戻ります。歌詞を表示している間、プレイヤーは自動でスリープしません。

  • 同期歌詞：今の行が中央に表示され、歌われるにつれて色で満たされます。長い間奏では 3 つのドットが表示され、歌が戻るまでに満ちていきます。
  • 同期していない歌詞：曲に合わせてスクロールします。↑/↓、指、ホイールで手動でスクロールできます。

歌詞の取得元

  1. 手動で選んだバージョン。
  2. 曲と同じ名前の .lrc ファイル（曲の隣、または lyrics フォルダー内）。
  3. ファイルのタグ：ID3 の SYLT と USLT、FLAC と Ogg の LYRICS、M4A の ©lyr。
  4. 無料のオンライン歌詞データベース LRCLIB（タイトル、アーティスト、長さで検索）。
  5. .txt やタグからの同期していない歌詞。

オンラインで見つけた歌詞は保存されるので、各曲の検索は一度だけです。LRCLIB でインストゥルメンタルとされている曲にはインストと表示されます。

別のバージョンとタイミングの選択

  • START → 歌詞を選ぶで、すべてのバージョンが一覧表示されます：ローカルファイル、タグ、LRCLIB のすべての候補（アルバムと長さ付き）、歌詞なし。選んだものはその曲について記憶されます。
  • ↑/↓ で同期歌詞を 0.5 秒早めたり遅らせたりできます。メニューのずれでリセットします。オフセットは曲ごとに保存されます。

ラジオでの歌詞

タイトルを「アーティスト - 曲名」の形式で送る局でも歌詞が表示されます。同期歌詞はタイトルが変わった時点から数えます。局はタイトルを数秒遅れて送ることが多いので、↑/↓ でタイミングを調整してください。

オフラインで使う

設定 → ネットの歌詞をオフにすると、ファイルとタグだけが使われます。
