設定

Settings のすべてのタイルをセクションごとに解説します。

設定はタイルになっています。スイッチは A で切り替わります。選択肢は A で開き、←/→ で選び（すぐに反映されます）、A か B で閉じます。設定は audiofilus.json に保存されます。

Library

  • Folder：音楽フォルダー。Rescan：新しい曲を探します。Servers：Subsonic、Navidrome、Jellyfin。

Playback

  • Shuffle、Repeat（Off、All、One）、Volume（0〜200 %）、Crossfade（Off〜12 秒）。

Sound

  • ReplayGain、Equalizer、Output rate：サウンドを参照してください。

Online

  • Scrobbling：Last.fm と ListenBrainz。Lyrics from the web：LRCLIB で歌詞を検索します。

Screen

  • Sleep after：何も触らない時間が Never（しない）、15 秒、30 秒、1、2、5 分でスリープ。音楽の再生中は Now Playing にいるときだけカウントします。
  • Sleep mode：Backlight はバックライトを消します。OLED (black) は画面を黒く塗るだけで、OLED 画面ではピクセルが消灯した状態になります。
  • 24 h clock（24 時間表示）。

スリープの設定は携帯ゲーム機でのみ表示されます。

System

  • Language：English、Español、Türkçe。
  • Music sounds と Interface sounds：Off、Low、Medium、High。音楽操作とメニューのチップチューン効果音です。
  • Swap A/B（A/B の入れ替え）。

About

  • GitHub と Buy me a coffee は QR コードを表示します。

Exit

  • Keep playing on close：Quit 以外でプレイヤーを閉じたときに音楽を鳴らし続けるかどうか。デスクトップではデフォルトでオン、携帯ゲーム機ではオフです。
  • Go to background：プレイヤーを閉じて音楽は続けます。Quit：すべて停止します。

iPhone では Output rate、Keep playing on close、Go to background は表示されません。アプリを離れても音楽はすでに鳴り続けるからです。
