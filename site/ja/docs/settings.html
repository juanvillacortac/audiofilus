設定

設定のすべてのタイルをセクションごとに解説します。

設定はタイルになっています。スイッチは A で切り替わります。選択肢は A で開き、←/→ で選び（すぐに反映されます）、A か B で閉じます。設定は audiofilus.json に保存されます。

ライブラリ

  • フォルダ：音楽フォルダー。再スキャン：新しい曲を探します。サーバー：Subsonic、Navidrome、Jellyfin。

再生

  • シャッフル、リピート（オフ、すべて、One）、音量（0〜200 %）、クロスフェード（オフ〜12 秒）。

サウンド

  • ReplayGain、イコライザー、出力レート：サウンドを参照してください。

オンライン

  • 再生の記録：Last.fm と ListenBrainz。ネットの歌詞：LRCLIB で歌詞を検索します。

画面

  • スリープまで：何も触らない時間がなし（しない）、15 秒、30 秒、1、2、5 分でスリープ。音楽の再生中は再生中にいるときだけカウントします。
  • スリープ方式：バックライトはバックライトを消します。OLED (black) は画面を黒く塗るだけで、OLED 画面ではピクセルが消灯した状態になります。
  • 24 h clock（24 時間表示）。

スリープの設定は携帯ゲーム機でのみ表示されます。

システム

  • 言語：English、Español、Português、Français、Italiano、Deutsch、Polski、Türkçe、Русский、Indonesia、日本語、中文、한국어。
  • 音楽の効果音と操作音：オフ、小、中、大。音楽操作とメニューのチップチューン効果音です。
  • A/B を入れ替え（A/B の入れ替え）。

情報

  • GitHub とコーヒーをおごるは QR コードを表示します。

終了

  • 閉じても再生：終了以外でプレイヤーを閉じたときに音楽を鳴らし続けるかどうか。デスクトップではデフォルトでオン、携帯ゲーム機ではオフです。
  • バックグラウンドへ：プレイヤーを閉じて音楽は続けます。終了：すべて停止します。

iPhone では出力レート、閉じても再生、「バックグラウンドへ」は表示されません。アプリを離れても音楽はすでに鳴り続けるからです。
