サウンド

ReplayGain、イコライザー、クロスフェード、出力サンプルレート。サービスが適用するので、プレイヤーを閉じても効きます。

すべて設定にあります。クロスフェードは再生に、それ以外はサウンドにあります。

ReplayGain

ファイルの ReplayGain タグ（Opus の R128 ゲインにも対応）を使って、すべての曲（またはアルバム）を同じ音量で再生します。設定 → ReplayGain：

  • 自動：順番に再生するときはアルバム単位、シャッフル時は曲単位。
  • 曲ごと（曲単位）またはアルバムごと（アルバム単位）。
  • オフ（オフ）。

曲のピークを超えることはないので、音割れしません。ReplayGain タグのない曲（とリモートの曲）はそのまま再生されます。

イコライザー

設定 → イコライザーで 31 Hz から 16 kHz までの 10 バンドが開きます。各バンドは −12 から +12 dB です。

ボタン動作
←/→バンドを選ぶ
↑/↓1 dB 動かす
X, L1/R1プリセットを切り替える：フラット、低音、高音、ボーカル、ロック、メタル、ポップ、エレクトロ、ジャズ、クラシック、ラウドネス
Yフラットに戻す
A / B閉じる（変更はその場で反映されます）

自分でバンドを動かすと、プリセットはカスタムになります。タッチスクリーンでは、列をタップするとその高さに設定されます。イコライザーがオンのとき、10 バンドの負荷は最低クロックの携帯ゲーム機で CPU の約 5 % です。フラットなら負荷はありません。

クロスフェード

設定 → クロスフェード：オフ、または曲と曲を 2〜12 秒重ねます。同じアルバムの連続する曲を順番に再生するときはフェードしないので、アルバムはギャップレスのままです。とても短い曲や、まだダウンロードが終わっていないサーバーの曲もスキップします。

出力サンプルレート

設定 → 出力レート：44.1、48、96、192 kHz。変更するとオーディオサービスが再起動し、元の位置から再開します。ファイルが同じレートで何も適用していないとき（音量 100 %、ReplayGain やイコライザーなし）は、サンプルは手を加えずに出力されます。ただし PipeWire や PulseAudio がリサンプリングすることはあります。iPhone では使えません。

音量とブースト

音量は 0 から 200 % まで。100 % まではシステムの音量で、それを超えると audiofilus がリミッター付きで信号を増幅するので、音圧の高いマスターでも歪みません。

DSD

DSF と DFF ファイルは PCM に変換して再生されます。DSD64 なら携帯ゲーム機でも軽く再生できますが、DSD256 は追いつかないことがあります。
