よくある質問

よくある質問への短い答え。

アプリを閉じると音楽が止まります。

バックグラウンドへ（再生中のその他メニュー、または設定 → 終了）を使うと、プレイヤーを閉じても音楽は続きます。それ以外の閉じ方（PortMaster の SELECT+START、ウィンドウを閉じる）では、設定 → 閉じても再生がオンのときだけ音楽が続きます。携帯ゲーム機ではデフォルトでオフ、デスクトップではオンです。終了は常にすべてを停止します。

ゲーム中に曲を変えるには？

FN を 3 回押してから、L1/R1（前 / 次）、L2/R2（10 秒移動）、SELECT（一時停止）を押します。ヘッドホンのボタンも使えます。

設定とデータはどこにありますか？

プログラムの隣です。設定は audiofilus.json、それ以外（ライブラリのキャッシュ、プレイリスト、履歴、歌詞、ポッドキャスト、ログ）はすべて data/ フォルダーにあります。ファイルの場所を参照してください。

muOS では PortMaster のポートと muOS アプリのどちらを使うべきですか？

どちらも同じように動きます。.muxapp は muOS の Archive Manager からインストールして Applications に表示され、PortMaster のポートは Ports に表示されます。設定とデータはそれぞれ別です。

どのフォーマットを再生できますか？

MP3、AAC/M4A、ALAC、FLAC、Ogg Vorbis、Opus、WAV、AIFF、DSD、トラッカーモジュール（MOD、XM、IT、S3M）、ゲーム機の音楽（NSF、SPC、GBS、VGM…）、M3U プレイリスト、CUE シート。対応フォーマットを参照してください。

NSF/SPC/VGM ファイルが再生されません。

ゲーム機の音楽には libgme が必要です。PortMaster のポート、muOS アプリ、Linux 版のダウンロードには同梱されています。プログラムだけをコピーしてインストールした場合は、libs.aarch64（または libs.x86_64）フォルダーも隣にコピーしてください。Linux デスクトップでは、ディストリビューションの libgme パッケージをインストールしてもかまいません。Windows 版のダウンロードにも含まれています。

YouTube Music が表示されません。

アプリの yt-dlp フォルダーに、ご自身で用意した yt-dlp が必要です。YouTube Music を参照してください。

歌詞が見つかりません。

設定 → ネットの歌詞がオンで、デバイスがオンラインか確認してください。LRCLIB にすべての曲があるわけではありません。曲と同じ名前の .lrc を曲の隣に置くか、歌詞 → START → 歌詞を選ぶで別のバージョンを選べます。見つからなかった検索は 1 週間後に再試行されます。

歌詞が早すぎる / 遅すぎる。

歌詞の画面で ↑/↓ を押すと 0.5 秒ずつずらせます。オフセットはその曲について保存されます。

Last.fm で「API キーなし」と表示されます。

お使いのビルドには audiofilus の Last.fm アプリケーションキーが含まれていません。公式リリースには含まれているので、最新版をダウンロードしてください。

ラジオ局が再生されません。

audiofilus が再生できるのは MP3 と AAC の局です。HLS ストリーム（.m3u8 で終わるアドレス）も再生できます。ただし、珍しいコーデック（AAC LATM や fMP4 の Opus/AC-3）を使う一部の局は除きます。アドレスが .pls や .m3u の局は、たどってストリームにつなぎます。

自分のラジオ局を追加できますか？

はい。.m3u/.pls のリストをアプリの radio フォルダーに置く（ラジオ → マイリストに表示されます）か、お気に入りかマイリストで START → アドレスで追加を使います。別のフォルダーは設定 → ラジオのリストで選べます。

バッテリー残量がおかしい。

audiofilus はシステムのバッテリー情報を読みます。バッテリー残量が常に 0 % と表示されるゲーム機（dArkOS の RG353V など）では、充電量か電圧から残量を推定し、できなければ表示しません。

dArkOS でアプリのフォルダーが見つかりません。

ゲームが 2 枚目の SD カードにある場合、ポートは /roms/ports ではなく /roms2/ports にあります。ログは /roms2/ports/audiofilus/data/audiofilus.log です。

EmuELEC で動きますか？

はい。PortMaster 経由で、Odroid Go Advance／Super、GameForce Chi、Amlogic の TV ボックスで動きます。実機ではまだ試していないので、うまくいかない場合は ports/audiofilus/log.txt を添えて issue を立ててください。EmuELEC を参照。

電源ボタンを押してもゲーム機がスリープしません。

プレイヤーが開いているとき、電源ボタンは audiofilus をスリープ（画面オフ、音楽オン）させるためのもので、ゲーム機をスリープさせません。「バックグラウンドへ」の後は通常どおりスリープします。ROCKNIX の「疑似サスペンド」については ROCKNIX を参照してください。

バッテリーはどれくらい使いますか？

わずかです。RG34XX-SP では、スリープモードの消費電流は約 260 mA で、音楽を 11〜12 時間ほど再生できます。ビジュアライザーとイコライザーはもう少し使いますが、画面オフ中は何も描画しません。

アップデートするには？

バージョン 0.9.1 からは 設定 → アップデート で行えます。新しいバージョンが出るとアプリがお知らせし、A でインストールします。設定はそのままです。それより前のバージョンは一度だけ手動でアップデートしてください。最新リリースから新しいパッケージをダウンロードし、古いものに上書きします。

iPhone にインストールするには？

最新リリースから audiofilus-ios-unsigned.ipa をダウンロードし、Sideloadly か AltStore でインストールすると、ご自身の Apple ID で署名されます。または、AltStore、SideStore、LiveContainer にソース https://juanvillacortac.github.io/audiofilus/altstore.json を追加すると、新しいリリースがアップデートとして表示されます。

iPhone で音楽を追加するには？

ファイルアプリの このiPhone内 → Audiofilus に曲をコピーするか、設定 → フォルダで任意のフォルダーを選ぶか、ファイルアプリや他のアプリから曲を Audiofilus で開きます。サーバー、ラジオ、ポッドキャストはローカルの音楽がなくても使えます。

ファイルマネージャーからファイルを開くには？

Linux では、右クリック → このアプリで開く → Audiofilus（インストーラーか audiofilus desktop install でインストールした後）。Windows では、audiofilus は初回起動時に自動で登録されるので、「プログラムから開く」か、フォルダーの「Play with Audiofilus」を使います。一時的なキューとして再生されます。

サーバーの曲はネットワークなしで使えますか？

カタログは保存されるのでオフラインでも閲覧でき、一度再生した曲はキャッシュされます（デフォルトで 400 MB）。キャッシュされていない曲にはサーバーが必要です。ずっと残したい曲はライブラリにダウンロードしてください。

audiofilus はオンラインに何を送信しますか？

使う機能に必要なものだけです：radio-browser（ラジオの画面）、Apple のポッドキャストディレクトリと RSS フィード（ポッドキャスト）、LRCLIB（歌詞。「ネットの歌詞」をオフにすれば送りません）、ご自身のサーバー、ご自身の yt-dlp 経由の YouTube、モジュールのアーカイブ（モジュール）、GitHub のリリース（1 日 1 回のアップデート確認）、そして接続した場合のみ Last.fm や ListenBrainz。MusicBrainz、Cover Art Archive、iTunes には、カバーを探すや MusicBrainz で検索を使ったときだけ接続します。スピーカーへの送信と DLNA はローカルネットワーク内だけで、DLNA はオンにしない限りオフです。

モジュールはどこから来るのですか？

4 つの無料オンラインアーカイブ、The Mod Archive、Modland、VGMRips、AMP からです（モジュールを参照）。聴くとファイルが data/cache/modules にダウンロードされるので、次からはすぐ再生されます。ライブラリに保存で、音楽フォルダーの audiofilus modules にコピーします。

MIDI キーボードは使えますか？

はい、トラッカーで使えます。USB MIDI キーボードを携帯機やパソコン（Linux、Windows、iPhone/iPad）につなぐと、ノートでいまのインストゥルメントが鳴り、フレーズに書き込むこともできます。MIDI クロックに従ったり、送ったりもできます。MIDI を参照してください。

テレビやスピーカーで再生できますか？

はい。再生中で START → 送信先… を選ぶと、ネットワーク上の DLNA/UPnP のスピーカーやテレビ、Chromecast が一覧に出ます。音楽はそちらで続き、audiofilus はリモコンになります。ネットワークを参照してください。

テレビやスマホから自分の音楽を見られますか？

設定 → ライブラリ共有 (DLNA) をオンにすると、同じネットワークのテレビや DLNA アプリにライブラリが表示されます。音楽を受信 (DLNA) をオンにすると、BubbleUPnP などのアプリから audiofilus に音楽を送って再生できます。どちらも初期状態ではオフです。ネットワークを参照してください。

間違ったタグや足りないジャケットを直せますか？

はい、自分のライブラリのファイルなら。曲やアルバムの START メニューにタグを編集、アルバムのタグ、カバーを探す、MusicBrainz で検索があり、MusicBrainz からタイトル、番号、年、ジャンルを埋められます。ライブラリを参照してください。

曲によって音量が違います。どうすればいいですか？

設定 → ReplayGain をオンにし、ReplayGain タグのない曲にはアルバムやアーティストで ReplayGain を計算を使ってください。音の大きさを測ってタグを書き込みます。サウンドを参照してください。

アーケードの VGM は再生できますか？

はい、携帯機と Linux 向けパッケージなら再生できます。VGM のほぼすべてのチップをエミュレートする libvgm を同梱しているので、アーケード基板（アウトラン、CPS1/2、System 16…）から NES、ゲームボーイ、OPL まで鳴ります。Windows と iPhone では VGM は libgme で再生され、こちらはメガドライブとマスターシステムのチップだけをエミュレートします。そこではほかのファイルは無音で再生する代わりに VGM chips not emulated と表示され、VGMRips でもそれらのパックは表示されません。

ビジュアライザーはトラッカーに反応しますか？

はい。トラッカーの再生中は、ビジュアライザー、ビートに合わせて動くゲーム、背景がその音楽に合わせて動きます。

手持ちの MilkDrop プリセットは使えますか？

はい、MilkDrop 1 のプリセット（.milk）なら使えます。アプリの milkdrop フォルダー（サブフォルダーも可）に入れて、MilkDrop ビジュアライザーを開いてください。ファイルを追加したら START → プリセットを再検索。MilkDrop 2 のプリセットも読み込めますが、シェーダーは無視されるので見た目が違うことがあります。MilkDrop を参照。開くには SELECT → ビジュアライザー を選び、←/→ で MilkDrop まで切り替えます（v0.12.0 以降）。別のフォルダーは設定 → MilkDrop のプリセットで選べます。

ボタンが本体の文字と合いません。

設定 → A/B と X/Y を入れ替え（システムセクション）をオンにしてください。Nintendo 式の表記（A が右、X が上）のゲーム機向けに、決定と戻る、X と Y を入れ替えます。選ぶときは、今決定として働いているボタンを押してください。

オーディオブックに対応していますか？

はい。.m4b、ジャンルがオーディオブックのファイル、Audiobooks フォルダーの中のものはブックとして再生されます。ブックごとに続きの位置を覚え、チャプターを表示し、30 秒スキップや音程を変えない速度変更ができます。オーディオブックを参照。

音楽で起こしてくれますか？

はい：設定 → アラーム。時刻、曜日、再生するものを選ぶと、音量が少しずつ上がります。プレーヤーを閉じていても鳴り、携帯機ではスリープから起こしますが、電源が切れているときは鳴りません。アラームを参照。
