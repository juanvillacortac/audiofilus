ラジオとポッドキャスト

何千もの局や自分のリストからのインターネットラジオと、ダウンロードと続きから再生に対応したポッドキャスト。

ラジオ

画面バー（SELECT）からラジオを開きます。タブは次のとおりです：

  • お気に入り：保存した局（局で START → お気に入りに追加）。
  • マイリスト：自分の局リスト（下記参照）。
  • 人気：あなたの国で最もよく聴かれている局。X で世界全体に切り替えます。国はメニューの国で変更します。
  • 検索：局名で検索（X または START で検索）。
  • ジャンル（ジャンル）。

局のデータは radio-browser.info から取得します。A で聴きます。局の再生中は L1/R1 でリストの前後の局に切り替えられ、局が送ってくれば今流れている曲名が表示されます。MP3 と AAC の局は再生できますが、HLS ストリームには対応していません。

自分の局リスト

  • .m3u、.m3u8、.pls の局リストを、アプリの隣の radio フォルダー（携帯ゲーム機ではポートのフォルダー内）に置いてください。ファイルに書かれた名前とロゴ付きでマイリストに表示されます。
  • アドレスで追加：お気に入りかマイリストで START を押すと、局のアドレスと名前を聞かれ、お気に入りに保存されます。
  • 局のアドレス自体がプレイリスト（listen.pls など）の場合、audiofilus はそれをたどってストリームにつなぎます。

ポッドキャスト

画面バーからポッドキャストを開きます。タブ：購読中（購読中）、人気（あなたの国の人気番組）、検索（検索）。購読中で START を押すと、RSS のアドレスでポッドキャストを追加できます。

  • ポッドキャストで A を押すとエピソードが新しい順に開きます。日付、長さ、再生済みか、どこまで聴いたか、ダウンロード済みかが表示されます。
  • エピソードは再生前に（ダウンロードのキュー経由で）ダウンロードされ、SD カードから再生されます。
  • 再生位置は記憶され、状況をつかみやすいよう 3 秒前から再開します。終わり近くまで聴くと、再生済みになります。
  • エピソードで START：聴く、ダウンロードまたはダウンロードの削除、再生済み / 未再生にする。ポッドキャストで：購読または削除、更新、新着をダウンロード（新しいエピソードをダウンロード）。
