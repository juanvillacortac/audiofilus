はじめに

デバイスに audiofilus をインストールして開き、音楽のフォルダーを指定します。

PortMaster 対応の携帯ゲーム機

Knulli、muOS、ROCKNIX、ArkOS、dArkOS で動作します。

  1. 最新リリースから audiofilus-portmaster.zip をダウンロードします。
  2. PortMaster でインストールするか、ports フォルダーに展開します。
  3. Ports から audiofilus を開きます。

ポートには、ゲーム機の音楽を再生するライブラリ（libgme）を含め、必要なものがすべて入っています。

muOS（PortMaster なし）

  1. 最新リリースから audiofilus.muxapp をダウンロードします。
  2. SD カード（または USB ドライブ）のルートにある ARCHIVE フォルダーにコピーします。
  3. muOS の Archive Manager を開いてインストールします。audiofilus は Applications に表示されます。

Linux デスクトップ

curl -fsSL https://juanvillacortac.github.io/audiofilus/install.sh | sh

audiofilus を ~/.local/share/audiofilus にインストールし、audiofilus を ~/.local/bin にリンクして、アプリランチャーに追加します（オーディオファイルとフォルダーの「このアプリで開く」付き）。もう一度実行すると更新され、設定はそのまま残ります。

手動の場合：audiofilus-linux-amd64.tar.gz（または -arm64）を好きな場所に展開し、./audiofilus desktop install を一度実行します。

Windows

Windows 10 以降では、audiofilus-windows-amd64.zip を好きな場所に展開して audiofilus.exe を実行します。MP3、FLAC、Ogg Vorbis、ALAC、WAV、AIFF はそのまま再生できます。AAC/M4A、Opus、トラッカーモジュールを使うには、MSYS2 の DLL を .exe の隣に置いてください：libfdk-aac-2.dll、libopusfile-0.dll（libopus-0.dll と libogg-0.dll も）、libmpg123-0.dll、libxmp-4.dll。ゲーム機の音楽はまだ Windows では使えません。

iPhone と iPad

各リリースには署名なしの audiofilus-ios-unsigned.ipa が含まれます。Sideloadly か AltStore でインストールすると、ご自身の Apple ID で署名されます。

または、AltStore、SideStore、LiveContainer にソース https://juanvillacortac.github.io/audiofilus/altstore.json を追加してください。新しいリリースがアップデートとして表示されます。

初回起動：音楽フォルダー

携帯ゲーム機やデスクトップでは、初めて audiofilus を開くとフォルダーブラウザーが表示されます。A でフォルダーを開き、B で上の階層へ、X で現在のフォルダーを使います。ライブラリのスキャンは一度だけで、プログレスバーが表示されます。次回以降の起動では、新しいファイルや変更されたファイルだけを読み込みます。フォルダーはあとから Settings → Folder で変更でき、Rescan で再スキャンできます。

自分の音楽がなくても大丈夫です。audiofilus は空のライブラリで起動するので、サーバー、ラジオ、ポッドキャスト、YouTube Music は使えます。

iPhone では、ファイルアプリの このiPhone内 → Audiofilus に曲をコピーするか、Settings → Folder で任意のフォルダー（iCloud Drive や他のアプリ）を選んでください。

画面の移動

  • SELECT で画面バー（Now playing、Library、Search、Queue、Radio、Podcasts、Games、Settings…）が開きます。2 回押すと前の画面に戻ります。
  • START で今いる画面の More メニューが開きます。
  • FN（キーボードでは F1）を押し続けると、その画面で各ボタンが何をするかが表示されます。

アップデート

新しいリリースを同じ方法でインストールします。設定（audiofilus.json）とデータ（data/）はプログラムの隣にあるので、そのまま残ります。
