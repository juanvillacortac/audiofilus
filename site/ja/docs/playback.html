音楽の再生

再生中、キュー、スリープタイマー、そしてバックグラウンドで音楽が鳴り続ける仕組み。

再生中

  • A または Y で一時停止と再開。
  • ←/→ を軽く押すと前の曲 / 次の曲、押し続けると巻き戻し / 早送り。L1/R1 でも曲を変えられ、L2/R2 で 10 秒移動します。
  • X でシャッフルのオン / オフ。X を 2 回押すとランダムに1 曲再生します。
  • ↑/↓ でレコードをスクラッチします。
  • B でライブラリへ、START でその他メニューが開きます。

その他メニューには、アルバムとアーティスト、歌詞、いいね、評価、スリープタイマー、リストに追加、キューを保存、キュー、シャッフル、リピート（オフ、すべて、One）、画面を消す、バックグラウンドへ、終了があります。

キュー

キュー画面には次に再生される曲が表示されます。次に再生は曲を今の曲のすぐ後に、キューに追加は最後に追加します。再生はギャップレスで、一時停止はフェードアウトし、キューと再生位置は再起動後も保持されます。

スリープタイマー

再生中 → その他 → スリープタイマー。A を押すたびに次の選択肢へ：15、30、45、60、90 分、曲の終わりで（曲の終わり）、またはオフ。ジャケットに月のアイコンと残り分数が表示されます。タイマーはサービスが管理するので、プレイヤーを閉じても動作します。

バックグラウンド再生

音楽は専用のサービスで鳴っていて、プレイヤーはリモコンにすぎません。どう閉じるかで音楽がどうなるかが決まります：

  • バックグラウンドへ（その他メニュー、または設定 → 終了）：プレイヤーは閉じ、音楽はゲーム中も鳴り続けます。ゲーム機は通常どおりスリープします。
  • 終了：すべて停止します。
  • それ以外の閉じ方（ウィンドウを閉じる、PortMaster の SELECT+START、クラッシュ）は設定 → 閉じても再生次第です。デスクトップではデフォルトでオン、携帯ゲーム機ではオフです。

ゲーム中からの操作

FN を 3 回続けて押し、1.5 秒以内に：

続けて動作
L1 / R1前の曲 / 次の曲
L2 / R210 秒戻る / 進む
SELECT一時停止 / 再開

プレイヤーが開いていても閉じていてもいつでも使え、システムやエミュレーターとぶつかりません。

スリープ：画面オフ、音楽オン

スリープは音楽を鳴らしたまま画面を消して CPU クロックを下げるので、ゲーム機をポケットに入れておけます。START を 2 回、電源ボタン、ふたを閉じる、再生中 → その他 → 画面を消す、または一定時間何も触らないこと（設定 → スリープまで）で入ります。スリープ中は、トリガーボタンがジェスチャーになります：

ジェスチャー動作
L1/R1 を 2 回前の曲 / 次の曲
L2/R2 を 2 回10 秒戻る / 進む
L1+L2 を同時に 2 回一時停止 / 再開
R1+R2 を同時に 2 回ランダムに1 曲
START または電源ボタン復帰（ふたを閉じているときは電源ボタンでは復帰しません）

1 回だけ押しても何も起きないので、ポケットの中で誤って押しても大丈夫です。振動モーターのあるデバイスでは、ジェスチャーごとに短く振動します。RG34XX-SP ではスリープ中の消費電流は約 260 mA で、音楽を 11〜12 時間ほど再生できます。

デスクトップではスリープとその設定は使えないため、表示されません。

ヘッドホンのボタン

Bluetooth や有線ヘッドホンのボタンで、プレイヤーが開いていても閉じていても音楽を操作できます。ボタンが 1 つのヘッドセットは一般的な決まりに従います：1 回で一時停止、2 回で次の曲、3 回で前の曲。

ファイルマネージャーからファイルを開く

audiofilus で開いたファイルやフォルダーは一時的なキューとして再生されます。フォルダーは中身がすべて展開され、プレイリストとしては保存されません（残したいときはキューを保存を使ってください）。プレイヤーがすでに開いていれば、新しいキューに切り替わるだけです。

  • Linux：右クリック → このアプリで開く → Audiofilus。オーディオファイル、M3U/PLS リスト、CUE シート、ゲーム機の音楽、フォルダーに対応します（インストーラーか audiofilus desktop install で設定されます）。
  • Windows：audiofilus は初回起動時に自動で登録されます。対応するすべてのファイルにプログラムから開く、フォルダーに Play with Audiofilus が追加されます。複数のファイルを選ぶとすべてキューに入ります。
  • iPhone と iPad：ファイルアプリや他のアプリから「このアプリで開く」または「共有」。

デスクトップでは

  • メディアキーとメディアバー：Linux では audiofilus が MPRIS に対応しているので、メディアキーやデスクトップのメディアウィジェットで操作できます。
  • システムトレイ（Linux と Windows）：クリックでプレイヤーを開き、中クリックで一時停止。メニューには再生中の曲、再生 / 一時停止、次、前、シャッフル、終了があります。
