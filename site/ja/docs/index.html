Audiofilus ドキュメント

Audiofilus の使い方のすべて：インストール、画面の移動、各画面と設定の働き。

Audiofilus は、Linux 携帯ゲーム機（Knulli、muOS、ROCKNIX、ArkOS、dArkOS、EmuELEC）、Linux と Windows のデスクトップ、iPhone と iPad 向けの音楽プレイヤーです。音楽はバックグラウンドのサービスで再生されるので、プレイヤーを閉じてもゲームを起動しても鳴り続けます。

初めての方ははじめにから読み、どの画面でも FN を押し続けてボタンを確認してください。
