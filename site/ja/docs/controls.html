操作方法

携帯ゲーム機のボタン、デスクトップのキーボード、タッチとマウスの操作です。

どの画面でも FN（F1）を押し続けると、その画面のボタンが表示されます。次の操作はどこでも使えます。

ボタンキーボード動作
SELECTTab画面バー。2 回押すと前の画面
STARTM画面のその他メニュー。素早く 2 回押すとスリープ
YSpace一時停止 / 再開
L1 / R1Q / E前の曲 / 次の曲
L2 / R2, / .10 秒戻る / 進む
AEnter決定 / 開く
BEsc, Backspace戻る
XSシャッフル
FNF1押し続けると操作ガイド

ゲーム中は START で一時停止します。左アナログスティックはどこでも十字キーと同じように使えます。設定 → A/B を入れ替えで決定と戻るを入れ替えられます。

プレイヤーを閉じているとき

ゲーム中からの操作（FN を 3 回）とスリープ中のジェスチャーを参照してください。

タッチとマウス

  • 行、ジャケット、タブ、メニューのタイル、設定のタイル、プレイヤーのボタン、プログレスバーをタップできます。行をタップすると開きます。
  • リストは指の動きに合わせて慣性スクロールします。マウスホイールでもスクロールできます。
  • 長押し（0.5 秒）は START、右クリックは B、中クリックで一時停止です。
  • 画面下のボタンヒントはタップできます。タッチ操作では名前付きの本物のボタンになります。
  • 縦画面では、ライブラリ、ラジオ、ポッドキャストのタブはボタンからドロップダウンで開きます。
  • ゲームには専用のタッチ操作があります（ビジュアライザーとゲームを参照）。
