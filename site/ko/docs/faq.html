자주 묻는 질문

흔한 질문에 대한 빠른 답.

앱을 닫으면 음악이 멈춰요.

음악은 그대로 두고 플레이어만 닫으려면 백그라운드로(재생 중 화면의 더보기 메뉴 또는 설정 → 나가기)를 쓰세요. 다른 방식으로 닫으면(PortMaster의 SELECT+START, 창 닫기) 설정 → 닫아도 재생이 켜져 있을 때만 음악이 계속돼요. 휴대용 게임기에선 기본으로 꺼져 있고, 데스크톱에선 켜져 있어요. 종료는 항상 모두 멈춰요.

게임을 하면서 곡을 바꾸려면 어떻게 하나요?

FN을 세 번 누른 다음 L1/R1(이전/다음), L2/R2(10초 이동), SELECT(일시정지)를 누르세요. 헤드폰 버튼도 작동해요.

설정과 데이터는 어디에 있나요?

프로그램 옆이에요. 설정은 audiofilus.json, 나머지(보관함 캐시, 재생목록, 기록, 가사, 팟캐스트, 로그)는 data/ 폴더에 있어요. 파일이 있는 곳을 보세요.

muOS에서는 PortMaster 포트와 muOS 앱 중 뭘 써야 하나요?

어느 쪽이든 똑같이 작동해요. .muxapp은 muOS의 Archive Manager로 설치하고 Applications에 나타나고, PortMaster 포트는 Ports에 나타나요. 설정과 데이터는 따로 보관돼요.

어떤 형식을 재생하나요?

MP3, AAC/M4A, ALAC, FLAC, Ogg Vorbis, Opus, WAV, AIFF, DSD, 트래커 모듈(MOD, XM, IT, S3M), 게임기 음악(NSF, SPC, GBS, VGM…), M3U 재생목록, CUE 시트. 형식을 보세요.

NSF/SPC/VGM 파일이 재생되지 않아요.

게임기 음악에는 libgme가 필요하고, PortMaster 포트, muOS 앱, 리눅스 다운로드에 들어 있어요. 프로그램만 복사해서 설치했다면 libs.aarch64(또는 libs.x86_64) 폴더도 옆에 복사하세요. 리눅스 데스크톱에서는 배포판의 libgme 패키지를 설치해도 돼요. 윈도우에서는 아직 쓸 수 없어요.

YouTube Music이 보이지 않아요.

앱의 yt-dlp 폴더에 직접 준비한 yt-dlp가 있어야 해요. YouTube Music을 보세요.

가사를 찾지 못해요.

설정 → 웹 가사가 켜져 있고 기기가 온라인인지 확인하세요. LRCLIB에 모든 곡이 있는 건 아니에요. 곡 이름과 같은 .lrc를 곡 옆에 두거나, 가사 → START → 가사 선택에서 다른 버전을 고를 수 있어요. 아무것도 찾지 못한 검색은 일주일 뒤에 다시 시도해요.

가사가 빠르거나 늦어요.

가사 화면에서 ↑/↓로 0.5초씩 옮길 수 있어요. 조정 값은 그 곡에 저장돼요.

Last.fm에서 “API 키 없음”이라고 나와요.

그 빌드에 audiofilus의 Last.fm 애플리케이션 키가 없어서예요. 공식 릴리스에는 들어 있으니 최신 버전을 내려받으세요.

라디오 방송국이 재생되지 않아요.

audiofilus는 MP3와 AAC 방송국을 재생해요. HLS 스트림(세그먼트가 있는 .m3u8로 끝나는 주소)은 지원하지 않아요. 주소가 .pls나 .m3u인 방송국은 따라가서 스트림을 찾아요.

내 라디오 방송국을 추가할 수 있나요?

네. 앱의 radio 폴더에 .m3u/.pls 목록을 넣거나(라디오 → 내 목록에 나와요), 즐겨찾기나 내 목록에서 START → 주소로 추가를 쓰세요.

배터리 잔량이 이상해요.

audiofilus는 시스템의 배터리 정보를 읽어요. 어떤 게임기는 배터리 게이지가 항상 0 %로 나오는데(dArkOS를 설치한 RG353V 등), 그럴 땐 충전량이나 전압으로 잔량을 추정하고, 안 되면 숨겨요.

dArkOS에서 앱 폴더를 못 찾겠어요.

게임이 두 번째 SD 카드에 있으면 포트는 /roms/ports가 아니라 /roms2/ports에 있어서, 로그는 /roms2/ports/audiofilus/data/audiofilus.log에 있어요.

전원 버튼을 눌러도 게임기가 절전되지 않아요.

플레이어가 열려 있을 때 전원 버튼은 절전이 아니라 audiofilus를 슬립에 넣는(화면은 끄고 음악은 켜고) 용도예요. 백그라운드로 나간 뒤에는 평소처럼 절전돼요. “가짜 절전”을 쓰는 ROCKNIX라면 ROCKNIX를 보세요.

배터리는 얼마나 쓰나요?

적게 써요. RG34XX-SP에서 슬립 모드는 약 260 mA를 써서, 음악을 11~12시간 정도 들을 수 있어요. 비주얼라이저와 이퀄라이저는 더 쓰지만, 화면이 꺼져 있으면 아무것도 그리지 않아요.

어떻게 업데이트하나요?

0.9.1 버전부터는 설정 → 업데이트에서 할 수 있어요. 새 버전이 나오면 앱이 알려 주고 A로 설치해요. 설정은 그대로예요. 그 전 버전은 한 번만 직접 업데이트해 주세요. 최신 릴리스에서 새 패키지를 내려받아 예전 것 위에 복사하면 돼요.

iPhone에는 어떻게 설치하나요?

최신 릴리스에서 audiofilus-ios-unsigned.ipa를 내려받아 본인의 Apple ID로 서명해 주는 Sideloadly나 AltStore로 설치하세요. 또는 AltStore, SideStore, LiveContainer에 소스 https://juanvillacortac.github.io/audiofilus/altstore.json을 추가하면 새 릴리스가 업데이트로 나타나요.

iPhone에서 음악은 어떻게 넣나요?

파일 앱의 나의 iPhone → Audiofilus에 곡을 복사하거나, 설정 → 폴더에서 아무 폴더나 고르거나, 파일 앱이나 다른 앱에서 곡을 Audiofilus로 여세요. 서버, 라디오, 팟캐스트는 로컬 음악 없이도 작동해요.

파일 관리자에서 파일을 열려면요?

리눅스에서는 오른쪽 클릭 → 연결 프로그램 → Audiofilus(설치 프로그램이나 audiofilus desktop install로 설치한 뒤). 윈도우에서는 audiofilus를 처음 실행할 때 스스로 등록되니, 연결 프로그램을 쓰거나 폴더에서 Play with Audiofilus를 고르세요. 임시 대기열로 재생돼요.

서버 곡은 네트워크 없이도 되나요?

목록이 저장되어 있어서 오프라인에서도 둘러볼 수 있고, 이미 들은 곡은 캐시돼요(기본 400 MB). 캐시되지 않은 곡은 서버가 필요해요. 계속 보관하려면 곡을 보관함에 받으세요.

audiofilus는 온라인으로 무엇을 보내나요?

쓰는 것만 보내요: radio-browser(라디오 화면), Apple의 팟캐스트 디렉터리와 RSS 피드(팟캐스트), LRCLIB(가사, 웹 가사를 끄지 않았다면), 내 서버, 내 yt-dlp를 통한 YouTube, 모듈 아카이브(모듈), GitHub 릴리스(하루 한 번 업데이트 확인), 그리고 연결했을 때만 Last.fm이나 ListenBrainz.

모듈은 어디서 오나요?

네 곳의 무료 온라인 아카이브, The Mod Archive, Modland, VGMRips, AMP에서 와요(모듈을 보세요). 들으면 파일이 data/cache/modules에 내려받아져서 다음에는 바로 재생돼요. 보관함에 저장은 음악 폴더의 audiofilus modules로 복사해요.

MIDI 키보드를 쓸 수 있나요?

네, 트래커에서요. USB MIDI 키보드를 휴대용 기기나 컴퓨터(리눅스, Windows, iPhone/iPad)에 연결하면 노트가 지금 악기로 소리 나거나 프레이즈에 적혀요. 트래커는 MIDI 클럭을 따르거나 보낼 수도 있어요. MIDI를 보세요.

비주얼라이저가 트래커에 반응하나요?

네. 트래커가 재생되는 동안 비주얼라이저, 박자를 따라가는 게임, 배경이 그 음악을 따라가요.
