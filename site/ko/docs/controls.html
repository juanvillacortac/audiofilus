조작

휴대용 게임기의 버튼, 데스크톱의 키보드, 터치와 마우스.

어느 화면에서든 FN(F1)을 누르고 있으면 그 화면의 버튼을 볼 수 있어요. 다음은 모든 화면에서 작동합니다.

버튼키보드기능
SELECTTab화면 바. 두 번 누르면 직전 화면
STARTM그 화면의 더보기 메뉴. 빠르게 두 번 누르면 슬립
YSpace일시정지 / 재개
L1 / R1Q / E이전 / 다음 곡
L2 / R2, / .10초 뒤로 / 앞으로
AEnter확인 / 열기
BEsc, Backspace뒤로
XS셔플
FNF1누르고 있으면 조작 가이드

게임에서는 START가 일시정지예요. 왼쪽 아날로그 스틱은 어디서나 십자키처럼 작동합니다. 설정 → A/B·X/Y 바꾸기로 확인과 뒤로, 그리고 X와 Y 버튼도 바꿀 수 있어요. 닌텐도식 표기(A가 오른쪽, X가 위)인 기기에서 쓰면 화면 도움말의 글자가 기기에 인쇄된 글자와 맞아요.

플레이어를 닫았을 때

게임 중 조작(FN 세 번)과 슬립 제스처를 보세요.

터치와 마우스

  • 줄, 커버, 탭, 메뉴 타일, 설정 타일, 플레이어 버튼, 진행 막대를 탭할 수 있어요. 줄을 탭하면 열립니다.
  • 목록은 손가락 아래에서 관성 스크롤되고, 마우스 휠로도 스크롤돼요.
  • 길게 누르기(0.5초)는 START, 오른쪽 클릭은 B, 가운데 클릭은 일시정지예요.
  • 아래쪽의 버튼 안내는 탭할 수 있고, 터치로 쓰면 이름이 붙은 진짜 버튼이 됩니다.
  • 세로 화면에서는 보관함, 라디오, 팟캐스트 탭이 버튼을 눌러 드롭다운으로 열려요.
  • 게임에는 전용 터치 조작이 있어요(비주얼라이저와 게임 참고).
