가사

부르는 대로 물드는 싱크 가사. 내 파일에서 가져오거나 온라인에서 찾아요.

가사 열기

재생 중 화면에서 더보기 → 가사를 열거나 비주얼라이저를 탭하세요. B로 돌아가요. 가사가 화면에 있는 동안에는 플레이어가 저절로 슬립에 들어가지 않아요.

  • 싱크 가사: 지금 줄이 가운데에 머물며 부르는 대로 색이 채워져요. 긴 간주에서는 점 세 개가 목소리가 돌아올 때까지 차올라요.
  • 비동기 가사: 곡에 맞춰 스크롤돼요. ↑/↓, 손가락, 휠로 직접 스크롤할 수도 있어요.

가사를 가져오는 곳

  1. 직접 고른 버전.
  2. 곡 이름과 같은 .lrc 파일(곡 옆이나 lyrics 폴더 안).
  3. 파일의 태그: ID3 SYLT와 USLT, FLAC과 Ogg의 LYRICS, M4A의 ©lyr.
  4. LRCLIB: 무료 온라인 가사 데이터베이스(제목, 아티스트, 길이로 찾아요).
  5. .txt나 태그의 비동기 가사.

온라인에서 찾은 가사는 저장돼서 곡마다 한 번만 찾아요. LRCLIB에서 연주곡으로 표시된 곡은 연주곡이라고 보여요.

다른 버전 고르기와 타이밍

  • START → 가사 선택에 모든 버전이 나와요: 로컬 파일, 태그, LRCLIB의 모든 결과(앨범과 길이 포함), 가사 없음. 고른 것은 그 곡에 대해 기억돼요.
  • ↑/↓로 싱크 가사를 0.5초 빠르게 또는 늦게 옮겨요. 메뉴의 싱크로 되돌릴 수 있어요. 조정 값은 곡마다 저장돼요.

라디오에서 가사

제목을 “아티스트 - 곡” 형식으로 보내는 방송국도 가사가 나와요. 싱크 가사는 제목이 바뀐 순간부터 세는데, 방송국이 몇 초 늦게 보내는 경우가 많으니 ↑/↓로 타이밍을 맞추세요.

오프라인으로 쓰기

설정 → 웹 가사를 끄면 내 파일과 태그만 써요.
