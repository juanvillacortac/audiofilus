네트워크

집에 있는 스피커나 TV로 재생하고, 다른 기기가 내 보관함을 둘러보게 하고, 휴대폰에서 휴대용 게임기로 음악을 보낼 수 있어요. 모든 것이 로컬 네트워크 안에서만 이뤄져요.

스피커나 TV로 보내기

재생 중에서 START → 보내기…를 고르면 약 3초 동안 네트워크의 기기를 찾아 목록으로 보여 줘요. DLNA/UPnP 스피커와 TV, 그리고 Chromecast(Chromecast 내장 TV, Google/Nest 스피커)예요.

  • 기기를 고르면 같은 초부터 곡이 거기서 이어져요. 휴대용 게임기나 컴퓨터는 일시 정지하고 리모컨이 돼요. 대기열의 다음 곡도 미리 보내 두어서 기기가 대기열을 계속 이어 가요.
  • 보내는 동안 위쪽 바에 → <기기>가 표시되고, 일시 정지·다음·이전·탐색은 기기를 조작해요. 진행 바는 기기의 재생 위치를 보여 줘요.
  • START → 기기 볼륨으로 기기 소리를 키우거나 줄여요. <기기>(으)로 보내기 중지는 기기를 멈추고 같은 곡의 같은 초부터 여기서 이어서 재생해요.
  • audiofilus가 재생하는 것은 무엇이든 보낼 수 있어요. MP3, FLAC, AAC/M4A, WAV, Ogg는 그대로 보내고, 모듈, 게임기 음악, DSD, CUE 트랙은 그 자리에서 WAV로 변환해요. Subsonic/Jellyfin 서버의 곡과 라디오 방송은 각자의 주소로 보내요.

보관함 공유하기(DLNA 서버)

설정 → 보관함 공유 (DLNA)를 켜면 같은 네트워크의 TV, 게임기, DLNA 앱에서 내 보관함이 audiofilus (<기기 이름>)로 보여요. 아티스트, 앨범, 곡, 재생목록, 폴더를 커버와 함께 둘러보고 거기서 재생할 수 있어요. TV가 모르는 형식은 WAV로 변환해 줘요. 공유되는 것은 audiofilus가 이미 스캔한 보관함이고, 서버의 곡은 공유되지 않아요.

음악 받기(DLNA 렌더러)

설정 → 음악 받기 (DLNA)를 켜면 휴대용 게임기나 컴퓨터가 다른 앱의 스피커가 돼요. 휴대폰의 BubbleUPnP, Windows의 장치로 캐스트, 그 밖의 UPnP 컨트롤 포인트에서 audiofilus를 골라 곡을 보내세요. 곡은 제목과 아티스트와 함께 audiofilus로 재생되고, 재생·일시 정지·탐색·볼륨은 보낸 앱이 조작해요. 곡마다 먼저 내려받은 뒤 재생하므로, Wi-Fi에서는 시작까지 잠깐 걸려요.

참고

  • DLNA 설정 두 가지는 처음에는 꺼져 있어요. 꺼져 있으면 네트워크에서 아무것도 기다리지 않아요.
  • 공유와 받기가 휴대용 게임기를 깨어 있게 하지는 않아요. 잠들면 깨어날 때까지 응답하지 않아요.
  • 컴퓨터의 방화벽이 기기가 audiofilus에 닿도록 허용해야 해요(미디어 포트는 매번 무작위로 정해져요).
  • 터미널에서는 audiofilus dlna로 상태를 보고, audiofilus dlna server on|off, audiofilus dlna renderer on|off, audiofilus dlna name <이름>으로 바꿀 수 있어요.
  • iPhone과 iPad에서는 처음 찾을 때 로컬 네트워크 사용 권한을 물어봐요.
