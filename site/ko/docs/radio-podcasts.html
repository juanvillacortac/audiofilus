라디오와 팟캐스트

수천 개 방송국이나 직접 만든 목록의 인터넷 라디오, 다운로드와 이어 듣기가 되는 팟캐스트.

라디오

화면 바(SELECT)에서 라디오를 여세요. 탭은 다음과 같아요.

  • 즐겨찾기: 저장한 방송국(방송국에서 START → 즐겨찾기에 추가).
  • 내 목록: 직접 만든 방송국 목록(아래 참고).
  • 인기: 내 나라에서 가장 많이 듣는 방송국. X를 누르면 전 세계로 바뀌어요. 국가는 메뉴의 국가에서 바꿔요.
  • 검색: 방송국 이름으로(X나 START로 검색).
  • 장르.

방송국은 radio-browser.info에서 가져와요. A로 듣고, 방송국이 재생되는 동안 L1/R1로 목록의 이전·다음 방송국으로 바꿔요. 방송국이 보내 주면 실시간 곡 제목이 나와요. MP3와 AAC 방송국, 그리고 HLS 스트림(.m3u8)도 재생돼요.

직접 만든 방송국 목록

  • 앱 옆의 radio 폴더(휴대용 게임기에서는 포트 폴더 안)에 .m3u, .m3u8, .pls 방송국 목록을 넣으세요. 파일에 적힌 이름과 로고와 함께 내 목록에 나타나요. 다른 폴더는 설정 → 라디오 목록에서 고를 수 있습니다.
  • 주소로 추가: 즐겨찾기나 내 목록에서 START를 누르면 방송국 주소와 이름을 묻고 즐겨찾기에 저장해요.
  • 방송국 주소가 그 자체로 재생목록이면(listen.pls처럼) audiofilus가 따라가서 스트림을 찾아요.

팟캐스트

화면 바에서 팟캐스트를 여세요. 탭: 구독 중, 인기(내 나라의 인기 프로그램), 검색. 구독 중에서 START를 누르면 RSS 주소로 팟캐스트를 추가해요.

  • 팟캐스트에서 A를 누르면 에피소드가 최신순으로 열려요. 날짜, 길이, 들었는지, 어디서 멈췄는지, 받았는지가 함께 나와요.
  • 에피소드는 재생 전에 (다운로드 대기열을 통해) 내려받아서 SD 카드에서 재생돼요.
  • 들은 위치를 기억하고, 흐름을 다시 잡을 수 있게 3초 앞에서 이어 들어요. 끝부분에 다다르면 들은 것으로 표시돼요.
  • 에피소드에서 START: 듣기, 다운로드 또는 다운로드 삭제, 들음/안 들음으로 표시. 팟캐스트에서는: 구독 또는 구독 취소, 새로고침, 새 에피소드 받기.
