휴대용 게임기 시스템

Knulli, muOS, ROCKNIX, ArkOS, dArkOS, EmuELEC에서 Audiofilus가 다르게 하는 일.

Audiofilus는 시작할 때 시스템을 감지해서, 덮개, 전원 버튼, 볼륨, 배터리에 그 시스템의 도구를 써요. Knulli를 설치한 Anbernic RG34XX-SP에서 테스트했어요.

파일이 있는 곳

설정(audiofilus.json)과 데이터(data/: 보관함 캐시, 재생목록, 기록, 가사, 팟캐스트, 로그 audiofilus.log)는 프로그램 옆, 포트 폴더에 있어요.

시스템폴더
Knulli/userdata/roms/ports/audiofilus
ArkOS, dArkOS/roms/ports/audiofilus, 게임이 두 번째 SD 카드에 있으면 /roms2/ports/audiofilus
EmuELEC/storage/roms/ports/audiofilus
muOS (앱)MUOS/application 아래의 앱 폴더

전원 버튼

  • 플레이어가 열려 있을 때 전원 버튼을 짧게 누르면 게임기를 절전시키는 대신 Audiofilus가 슬립에 들어가요(화면은 끄고 음악은 켜고). 길게 누르면 여전히 전원이 꺼져요.
  • 백그라운드로 나간 뒤에는 누르면 게임기가 평소처럼 절전에 들어가요.

플레이어가 열려 있는 동안에는 시스템의 자동 절전과 화면 어두워짐도 막아요.

Knulli

  • 플레이어가 열려 있는 동안 볼륨 버튼은 Audiofilus를 거치므로 100 %를 넘길 수 있어요.
  • 덮개를 닫으면 Audiofilus가 슬립에 들어가요. 덮개를 열어도 깨어나지 않고, START로 깨워요.

muOS

  • PortMaster로 설치하거나 네이티브 앱(audiofilus.muxapp, 시작하기 참고)으로 설치하세요.
  • 100 %를 넘는 볼륨은 앱에서 올리고, 시스템 볼륨은 muOS 자체 버튼이 맡아요.

ROCKNIX

  • ROCKNIX의 “가짜 절전”(설정에서 절전 모드 끔)에서는 전원 버튼을 누르면 모든 게 음소거되고 멈추며, Audiofilus는 이를 막을 수 없어요. 보통 절전(기본값)에서는 버튼을 누르면 Audiofilus가 슬립에 들어가요.

ArkOS와 dArkOS

  • 배터리 게이지가 항상 0 %로 나오는 게임기(dArkOS를 설치한 RG353V 등)에서는 충전량이나 전압으로 배터리 잔량을 추정하거나 숨겨요.

EmuELEC

  • Odroid Go Advance와 Super, GameForce Chi, Amlogic TV 박스에서 실행돼요. 아직 실제 기기에서는 테스트하지 않았어요.
  • 휴대용 게임기에서는 플레이어가 열려 있을 때 전원 버튼을 누르면 게임기가 절전되는 대신 Audiofilus가 슬립에 들어가요. TV 박스는 절전되지 않아요.
  • 먼저 EmuELEC 메뉴에서 PortMaster를 설치하세요. 직접 설치할 때는 Audiofilus.sh를 /storage/roms/ports_scripts(EmuELEC가 포트 목록을 읽는 곳)에, audiofilus 폴더를 /storage/roms/ports에 넣으세요.

배터리 사용량

RG34XX-SP에서 측정한 결과: 슬립 중 Audiofilus는 약 260 mA를 써서, 3300 mAh 배터리로 음악을 11~12시간 정도 들을 수 있어요.
