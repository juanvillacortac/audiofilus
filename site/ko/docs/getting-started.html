시작하기

기기에 audiofilus를 설치하고, 열고, 음악 폴더를 지정하세요.

PortMaster로 휴대용 게임기에 설치

Knulli, muOS, ROCKNIX, ArkOS, dArkOS, EmuELEC에서 작동해요.

  1. 최신 릴리스에서 audiofilus-portmaster.zip을 내려받으세요.
  2. PortMaster로 설치하거나 ports 폴더에 압축을 푸세요.
  3. Ports에서 audiofilus를 여세요.

포트에는 게임기 음악을 재생하는 라이브러리(libgme)를 포함해 필요한 게 모두 들어 있어요.

EmuELEC에서는 실행 스크립트가 다른 폴더에 들어가요. EmuELEC를 보세요.

muOS에서 PortMaster 없이 설치

  1. 최신 릴리스에서 audiofilus.muxapp을 내려받으세요.
  2. SD 카드(또는 USB 드라이브) 최상위의 ARCHIVE 폴더에 복사하세요.
  3. muOS의 Archive Manager를 열고 설치하세요. audiofilus가 Applications에 나타납니다.

리눅스 데스크톱

curl -fsSL https://juanvillacortac.github.io/audiofilus/install.sh | sh

audiofilus를 ~/.local/share/audiofilus에 설치하고, audiofilus를 ~/.local/bin에 링크하고, 앱 런처에 추가해요(오디오 파일과 폴더를 “연결 프로그램”으로 열 수 있게). 업데이트하려면 다시 실행하세요. 설정은 그대로 남아요.

직접 설치: audiofilus-linux-amd64.tar.gz(또는 -arm64)를 아무 데나 풀고 ./audiofilus desktop install을 한 번 실행하세요.

윈도우

윈도우 10 이상에서는 audiofilus-windows-amd64.zip을 아무 데나 풀고 audiofilus.exe를 실행하세요. 모두 바로 재생돼요. AAC/M4A, Opus, 트래커 모듈, 게임기 음악(NSF, SPC, GBS…), AAC나 HLS 라디오 방송국도요. zip에는 디코더 DLL이 .exe 옆에 들어 있어요(MSYS2의 mpg123, opusfile, libxmp, libgme와 fdk-aac). 라이선스는 licenses 폴더에 있어요.

iPhone과 iPad

릴리스마다 서명되지 않은 audiofilus-ios-unsigned.ipa가 있어요. 본인의 Apple ID로 서명해 주는 Sideloadly나 AltStore로 설치하세요.

또는 AltStore, SideStore, LiveContainer에 소스 https://juanvillacortac.github.io/audiofilus/altstore.json을 추가하면 새 릴리스가 업데이트로 나타납니다.

처음 실행: 음악 폴더

휴대용 게임기나 데스크톱에서 audiofilus를 처음 열면 폴더 탐색기가 나와요. A는 폴더 열기, B는 위로, X는 지금 폴더를 사용합니다. 보관함은 진행 막대와 함께 한 번 스캔되고, 이후 실행할 땐 새로 생기거나 바뀐 파일만 읽어요. 폴더는 나중에 설정 → 폴더에서 바꿀 수 있고, 다시 스캔으로 다시 읽을 수 있어요.

내 음악이 없나요? 그래도 빈 보관함으로 열리니, 서버, 라디오, 팟캐스트, YouTube Music은 그대로 쓸 수 있어요.

iPhone에서는 파일 앱의 나의 iPhone → Audiofilus에 곡을 복사하거나, 설정 → 폴더에서 아무 폴더(iCloud Drive나 다른 앱)나 고르세요.

화면 둘러보기

  • SELECT를 누르면 화면 바(재생 중, 보관함, 검색, 대기열, 라디오, 팟캐스트, 게임, 설정…)가 열려요. 두 번 누르면 직전 화면으로 돌아갑니다.
  • START를 누르면 지금 화면의 더보기 메뉴가 열려요.
  • FN(키보드에선 F1)을 누르고 있으면 그 화면에서 각 버튼이 하는 일을 볼 수 있어요.

업데이트

새 릴리스를 같은 방법으로 설치하세요. 설정(audiofilus.json)과 데이터(data/)는 프로그램 옆에 있어서 그대로 남아요.
