Subsonic, Navidrome e Jellyfin

Usa un server musicale come un'altra libreria, con streaming, cache, preferiti e conteggio degli ascolti.

Aggiungere un server

Impostazioni → Server → Aggiungi server. Scegli il tipo (Subsonic/OpenSubsonic, che comprende Navidrome, gonic, Airsonic e altri; oppure Jellyfin/Emby), poi inserisci un nome, l'indirizzo (http://ip:porta), il tuo utente e la password. La connessione viene provata prima di salvare; se non risponde puoi riprovare, correggere i dati o salvare comunque.

Ogni server diventa una libreria in più nella barra delle schermate, con album, artisti, brani, playlist e ricerca. Il suo catalogo viene salvato, quindi compare subito anche senza rete.

Opzioni per server

  • Qualità d'ascolto: MP3 a 192 kbps di serie (poco da scaricare, leggero da decodificare), 320, 128, 96, oppure Originale (senza conversione).
  • Prova connessione, Aggiorna catalogo, Cambia i dati, Togli server.

Streaming e cache

I brani restano in cache sulla scheda SD mentre suonano (400 MB di serie; i meno usati di recente se ne vanno per primi), e il brano successivo si scarica in anticipo. I brani in cache suonano senza rete. Puoi anche usare Scarica in libreria sui brani di un server, con tag e copertina, nella tua cartella della musica.

Preferiti, voti e conteggio degli ascolti

  • Mettere Mi piace o un voto a un brano di un server lo segna anche sul server. Jellyfin ha i preferiti ma non i voti da 1 a 5.
  • Quando si carica il catalogo di un server, i suoi brani con la stella o con un voto vengono aggiunti alla tua lista Mi piace.
  • Anche i brani che ascolti contano sul server (Navidrome può inoltrarli a Last.fm e ListenBrainz, se lo configuri lì). Disattivalo in Impostazioni → Scrobbling → Conta sul server.

Modificare le playlist del server

Mentre sfogli un server, le sue playlist si possono cambiare, e le modifiche vanno al server:

  • Il menu START di una playlist: Rinomina, Elimina playlist (chiede prima) e Nuova playlist su <server>.
  • Un brano dentro una playlist del server: Sposta su, Sposta giù e Togli dalla playlist.
  • In una playlist sui brani di un server offre le playlist di quel server, più una nuova su di esso. I brani locali continuano ad andare nelle tue playlist: le due cose non si mescolano.
