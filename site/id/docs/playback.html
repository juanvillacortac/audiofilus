Memutar musik

Sedang diputar, antrean, timer tidur, dan bagaimana musik tetap jalan di latar belakang.

Sedang diputar

  • A atau Y menjeda dan melanjutkan.
  • Ketuk ←/→ untuk lagu sebelumnya atau berikutnya; tahan untuk mundur atau maju cepat. L1/R1 juga mengganti lagu dan L2/R2 melompat 10 detik.
  • X menyalakan atau mematikan acak; X dua kali memutar lagu acak.
  • ↑/↓ menggores vinilnya.
  • B ke pustaka, START membuka menu Lainnya.

Menu Lainnya berisi album dan artis, Lirik, Suka, Rating, Timer tidur, Tambah ke playlist, Simpan antrean, Antrean, Acak, Ulangi (Mati, Semua, Satu lagu), Matikan layar, Ke latar belakang, dan Keluar.

Antrean

Layar Antrean menampilkan apa yang diputar berikutnya. Putar berikutnya menaruh lagu tepat setelah lagu saat ini; Tambah ke antrean menaruhnya di akhir. Pemutaran tanpa jeda, menjeda memudarkan suara, dan antrean serta posisinya bertahan setelah aplikasi dimulai ulang.

Timer tidur

Sedang diputar → Lainnya → Timer tidur. Setiap A pindah ke pilihan berikutnya: 15, 30, 45, 60, atau 90 menit, Akhir lagu, atau mati. Bulan dengan sisa menit tampil di sampul. Layanan yang menyimpan timernya, jadi tetap berfungsi saat pemutar ditutup.

Putar di latar belakang

Musiknya hidup di layanannya sendiri; pemutar hanyalah remote. Cara menutupnya menentukan apa yang terjadi pada musik:

  • Ke latar belakang (menu Lainnya, atau Pengaturan → Keluar): pemutar tertutup dan musik tetap berputar, juga di dalam game. Konsol suspend seperti biasa.
  • Keluar: menghentikan semuanya.
  • Menutupnya dengan cara lain (menutup jendela, SELECT+START dari PortMaster, atau crash) tergantung pada Pengaturan → Tetap putar saat ditutup: aktif secara bawaan di desktop, nonaktif di handheld.

Kontrol dari dalam game

Tekan FN tiga kali berturut-turut, lalu dalam 1,5 detik:

LaluFungsi
L1 / R1Lagu sebelum / berikut
L2 / R2Mundur / maju 10 dtk
SELECTJeda / lanjut

Selalu berfungsi, dengan pemutar terbuka atau tertutup, dan tidak bentrok dengan sistem atau emulator.

Tidur: layar mati, musik jalan

Mode tidur mematikan layar dan menurunkan kecepatan CPU sementara musik berputar, supaya konsol bisa dibawa di saku. Masuk dengan START dua kali, tombol power, menutup lipatan, Sedang diputar → Lainnya → Matikan layar, atau setelah beberapa saat tanpa menyentuh apa pun (Pengaturan → Tidur setelah). Selama tidur, tombol pemicu menjadi gestur:

GesturFungsi
L1/R1 dua kaliLagu sebelum / berikut
L2/R2 dua kaliMundur / maju 10 dtk
L1+L2 bersamaan, dua kaliJeda / lanjut
R1+R2 bersamaan, dua kaliLagu acak
START atau tombol powerBangunkan (tombol power tidak berfungsi saat lipatan tertutup)

Sekali tekan tidak melakukan apa-apa, jadi tekanan tak sengaja di saku tidak dihitung. Di perangkat dengan motor getar, setiap gestur memberi getaran singkat. Di RG34XX-SP mode tidur memakai sekitar 260 mA: kira-kira 11 sampai 12 jam musik.

Di desktop, mode tidur dan pengaturannya tidak berlaku dan disembunyikan.

Tombol headphone

Tombol headphone Bluetooth dan kabel mengendalikan musik dengan pemutar terbuka atau tertutup. Headset satu tombol mengikuti kebiasaan umum: sekali tekan jeda, dua kali lewati ke lagu berikutnya, tiga kali kembali.

Membuka file dari pengelola file

File dan folder yang kamu buka dengan audiofilus diputar sebagai antrean sementara: folder dibuka beserta semua isinya, dan tidak ada yang disimpan sebagai playlist (pakai Simpan antrean untuk menyimpannya). Jika pemutar sudah terbuka, ia hanya beralih ke antrean baru.

  • Linux: klik kanan → Buka dengan → Audiofilus, untuk file audio, daftar M3U/PLS, CUE sheet, musik konsol, dan folder (disiapkan oleh installer atau audiofilus desktop install).
  • Windows: audiofilus mendaftarkan dirinya saat pertama kali dibuka: Buka dengan pada setiap file yang didukung, dan Play with Audiofilus pada folder. Memilih beberapa file akan mengantrekan semuanya.
  • iPhone dan iPad: “Buka di” atau “Bagikan” dari aplikasi File dan aplikasi lain.

Di desktop

  • Tombol media dan bilah: di Linux audiofilus mendukung MPRIS, jadi tombol media dan widget media desktopmu bisa mengendalikannya.
  • System tray (Linux dan Windows): klik untuk membuka pemutar, klik tengah untuk jeda, dan menu berisi lagu yang diputar, putar/jeda, berikutnya, sebelumnya, acak, dan keluar.
