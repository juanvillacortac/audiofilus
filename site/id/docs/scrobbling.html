Scrobbling

Catat apa yang kamu dengarkan di Last.fm dan ListenBrainz.

Pengaturan → Scrobbling berisi kedua akun. Sebuah lagu dihitung setelah setengahnya diputar (atau empat menit), jika durasinya minimal 30 detik; “now playing” dikirim beberapa detik setelah lagu mulai. Layanan yang mengirimnya, jadi tetap berfungsi saat pemutar ditutup. Radio dan episode podcast tidak di-scrobble.

Last.fm

  1. Pilih Last.fm. Kode QR dengan halaman otorisasi Last.fm akan muncul.
  2. Pindai dengan ponselmu dan izinkan audiofilus dengan akun Last.fm-mu.
  3. Dalam beberapa detik audiofilus menampilkan bahwa ia terhubung sebagai penggunamu.

Pilih lagi untuk memutus koneksi. Jika muncul Kunci API tidak ada, build-mu tidak menyertakan kunci aplikasi Last.fm milik audiofilus; rilis resmi menyertakannya.

ListenBrainz

Pilih ListenBrainz dan ketik token penggunamu (dari halaman pengaturan ListenBrainz). audiofilus memeriksanya dan menampilkan nama penggunamu.

Tanpa koneksi

Riwayat dengar yang tidak bisa dikirim akan menunggu dan dikirim saat koneksi kembali (dicoba ulang setiap beberapa menit). Token yang salah atau sesi yang dicabut dibuang, tidak dicoba ulang.

Di servermu

Lagu dari server Subsonic atau Jellyfin juga dihitung di server itu, kecuali kamu mematikan Hitung di server.
