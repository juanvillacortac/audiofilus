Kontrol

Tombol di handheld, keyboard di desktop, serta sentuh dan mouse.

Tahan FN (F1) di layar mana pun untuk melihat tombolnya. Yang ini berlaku di mana saja:

TombolKeyboardFungsi
SELECTTabBilah layar; dua kali, layar sebelumnya
STARTMMenu Lainnya di layar itu; dua kali cepat, tidur
YSpaceJeda / lanjut
L1 / R1Q / ELagu sebelum / berikut
L2 / R2, / .Mundur / maju 10 dtk
AEnterTerima / buka
BEsc, BackspaceKembali
XSAcak
FNF1Tahan untuk panduan kontrol

Di game, START malah menjeda. Stik analog kiri berfungsi seperti D-pad di mana saja. Pengaturan → Tukar A/B dan X/Y menukar terima dan kembali, juga tombol X dan Y: pakai di konsol dengan huruf gaya Nintendo (A di kanan, X di atas), supaya huruf di petunjuk layar sama dengan yang tercetak di konsolmu.

Saat pemutar ditutup

Lihat Kontrol dari dalam game (FN tiga kali) dan gestur Tidur.

Sentuh dan mouse

  • Ketuk baris, sampul, tab, ubin menu, ubin Pengaturan, tombol pemutar, dan bilah progres. Mengetuk baris akan membukanya.
  • Daftar bergulir mengikuti jarimu dengan momentum; roda mouse juga menggulirnya.
  • Tekan lama (setengah detik) sama dengan START; klik kanan adalah B; klik tengah menjeda.
  • Petunjuk tombol di bawah bisa diketuk; dengan sentuhan, petunjuk itu jadi tombol sungguhan yang bernama.
  • Dalam posisi potret, tab pustaka, Radio, dan Podcast dibuka dari sebuah tombol sebagai menu tarik-turun.
  • Game punya kontrol sentuhnya sendiri (lihat Visualisasi dan game).
