Pertanyaan yang sering diajukan

Jawaban cepat untuk pertanyaan umum.

Musik berhenti saat aplikasi kututup.

Pakai Ke latar belakang (menu Lainnya di Sedang diputar, atau Pengaturan → Keluar) untuk menutup pemutar dan tetap mendengarkan musik. Menutupnya dengan cara lain (SELECT+START dari PortMaster, menutup jendela) hanya mempertahankan musik jika Pengaturan → Tetap putar saat ditutup aktif; secara bawaan nonaktif di handheld dan aktif di desktop. Keluar selalu menghentikan semuanya.

Bagaimana cara ganti lagu saat sedang main game?

Tekan FN tiga kali, lalu L1/R1 (sebelumnya/berikutnya), L2/R2 (maju-mundur 10 dtk) atau SELECT (jeda). Tombol headphone juga berfungsi.

Di mana pengaturan dan dataku?

Di samping program: audiofilus.json untuk pengaturan dan folder data/ untuk yang lainnya (cache pustaka, playlist, riwayat, lirik, podcast, log). Lihat Di mana file-filemu berada.

Di muOS, sebaiknya pakai port PortMaster atau aplikasi muOS?

Keduanya sama saja. .muxapp diinstal dari Archive Manager muOS dan muncul di Applications; port PortMaster muncul di Ports. Keduanya menyimpan pengaturan dan data masing-masing.

Format apa saja yang bisa diputar?

MP3, AAC/M4A, ALAC, FLAC, Ogg Vorbis, Opus, WAV, AIFF, DSD, modul tracker (MOD, XM, IT, S3M), musik konsol (NSF, SPC, GBS, VGM…), playlist M3U, dan CUE sheet. Lihat Format.

File NSF/SPC/VGM-ku tidak bisa diputar.

Musik konsol butuh libgme, yang sudah dibawa oleh port PortMaster, aplikasi muOS, dan unduhan Linux. Jika kamu menginstal dengan hanya menyalin programnya, salin juga folder libs.aarch64 (atau libs.x86_64) ke sampingnya. Di desktop Linux kamu juga bisa menginstal paket libgme dari distribusimu. Unduhan Windows juga sudah menyertakannya.

YouTube Music tidak muncul.

Ia butuh yt-dlp milikmu sendiri di folder yt-dlp aplikasi. Lihat YouTube Music.

Lirik tidak ditemukan.

Pastikan Pengaturan → Lirik dari internet aktif dan perangkat sedang online. LRCLIB tidak punya semua lagu; kamu bisa menaruh .lrc dengan nama lagunya di sampingnya, atau memilih versi lain di Lirik → START → Pilih lirik. Pencarian yang tidak menemukan apa-apa dicoba lagi setelah seminggu.

Liriknya terlalu cepat atau terlambat.

Di tampilan lirik, ↑/↓ menggesernya setengah detik setiap kali; offset-nya disimpan untuk lagu itu.

Last.fm bilang “Kunci API tidak ada”.

Build-mu tidak menyertakan kunci aplikasi Last.fm milik audiofilus. Rilis resmi menyertakannya; unduh yang terbaru.

Stasiun radio tidak mau diputar.

audiofilus memutar stasiun MP3 dan AAC. Stream HLS (alamat yang berakhiran .m3u8) juga bisa diputar, kecuali sebagian kecil yang memakai codec langka (AAC LATM, atau Opus/AC-3 dalam fMP4). Stasiun yang alamatnya berupa .pls atau .m3u diikuti sampai ke stream-nya.

Bisakah aku menambahkan stasiun radioku sendiri?

Bisa: taruh daftar .m3u/.pls di folder radio aplikasi (muncul di Radio → Daftarku), atau pakai START → Tambah lewat alamat di Favorit atau Daftarku. Kamu bisa memilih folder lain di Pengaturan → Daftar radio.

Level baterainya terlihat salah.

audiofilus membaca baterai dari sistem. Pengukur baterai beberapa konsol selalu melaporkan 0 % (seperti RG353V dengan dArkOS); di sana audiofilus memperkirakan levelnya dari muatan atau tegangan, atau menyembunyikannya jika tidak bisa.

Di dArkOS aku tidak bisa menemukan folder aplikasinya.

Jika game-mu ada di kartu SD kedua, port berada di /roms2/ports, bukan /roms/ports, jadi log-nya ada di /roms2/ports/audiofilus/data/audiofilus.log.

Apakah berjalan di EmuELEC?

Ya, lewat PortMaster, di Odroid Go Advance dan Super, GameForce Chi, serta TV box Amlogic. Belum dicoba di perangkat sungguhan: kalau ada yang gagal, buka issue dengan ports/audiofilus/log.txt. Lihat EmuELEC.

Menekan tombol power tidak membuat konsol suspend.

Saat pemutar terbuka, tombol power memang dibuat untuk menidurkan audiofilus (layar mati, musik jalan), bukan untuk suspend. Setelah Ke latar belakang, konsol suspend seperti biasa. Di ROCKNIX dengan “fake suspend”, lihat ROCKNIX.

Seberapa boros baterainya?

Sedikit: di RG34XX-SP, mode tidur memakai sekitar 260 mA, kira-kira 11 sampai 12 jam musik. Visualisasi dan ekualiser memakai lebih banyak; saat layar mati, tidak ada yang digambar.

Bagaimana cara memperbarui?

Mulai versi 0.9.1, di Pengaturan → Perbarui: aplikasi memberi tahu kalau ada versi baru dan memasangnya dengan A, pengaturanmu tetap. Versi lama perlu diperbarui manual sekali: unduh paket baru dari rilis terbaru lalu salin menimpa yang lama.

Bagaimana cara menginstalnya di iPhone?

Unduh audiofilus-ios-unsigned.ipa dari rilis terbaru dan instal dengan Sideloadly atau AltStore, yang menandatanganinya dengan Apple ID-mu sendiri. Atau tambahkan sumber https://juanvillacortac.github.io/audiofilus/altstore.json ke AltStore, SideStore, atau LiveContainer: rilis baru muncul di sana sebagai pembaruan.

Bagaimana cara menambahkan musik di iPhone?

Salin lagu ke Di iPhone Saya → Audiofilus di aplikasi File, pilih folder mana pun di Pengaturan → Folder, atau buka lagu di Audiofilus dari File atau aplikasi lain. Server, radio, dan podcast bisa dipakai tanpa musik lokal.

Bagaimana cara membuka file dari pengelola file?

Di Linux, klik kanan → Buka dengan → Audiofilus (setelah menginstal dengan installer atau audiofilus desktop install). Di Windows, audiofilus mendaftarkan dirinya saat pertama kali dijalankan: pakai Buka dengan, atau Play with Audiofilus pada folder. Semuanya diputar sebagai antrean sementara.

Apakah lagu dari server bisa diputar tanpa jaringan?

Katalognya disimpan, jadi kamu bisa menjelajah secara offline, dan lagu yang sudah pernah kamu putar tersimpan di cache (400 MB secara bawaan). Lagu yang tidak ada di cache butuh server. Unduh lagu ke pustakamu untuk menyimpannya selamanya.

Apa yang dikirim audiofilus ke internet?

Hanya yang kamu pakai: radio-browser (layar radio), direktori podcast Apple dan feed RSS (Podcast), LRCLIB (lirik, kecuali kamu mematikan Lirik dari internet), server milikmu sendiri, YouTube lewat yt-dlp milikmu, arsip modul (Modul), MusicBrainz, Cover Art Archive, dan iTunes (hanya saat kamu memakai Cari sampul atau Cari di MusicBrainz), rilis GitHub (pemeriksaan pembaruan harian), serta Last.fm atau ListenBrainz hanya jika kamu menghubungkannya. Mengirim ke speaker dan DLNA tetap di jaringan lokalmu, dan DLNA mati kecuali kamu menyalakannya.

Dari mana modul-modulnya berasal?

Dari empat arsip online gratis: The Mod Archive, Modland, VGMRips, dan AMP (lihat Modul). Mendengarkan mengunduh berkas ke data/cache/modules, jadi lain kali langsung diputar; Simpan ke pustaka menyalinnya ke audiofilus modules di folder musikmu.

Bisakah aku memakai keyboard MIDI?

Bisa, di tracker: colokkan keyboard MIDI USB ke handheld atau komputer (Linux, Windows, iPhone/iPad), dan not-notnya memainkan instrumen saat ini atau ditulis ke frasa. Tracker juga bisa mengikuti atau mengirim MIDI clock. Lihat MIDI.

Bisakah memutar di TV atau speaker-ku?

Bisa: di Sedang diputar, START → Kirim ke… menampilkan speaker dan TV DLNA/UPnP serta Chromecast di jaringanmu. Musik berlanjut di sana dan audiofilus menjadi remote. Lihat Jaringan.

Bisakah TV atau ponselku melihat musikku?

Nyalakan Pengaturan → Bagikan pustaka (DLNA) dan pustakamu muncul di TV dan aplikasi DLNA di jaringan yang sama. Dengan Terima musik (DLNA), aplikasi seperti BubbleUPnP bisa mengirim musik ke audiofilus untuk diputar. Keduanya mati secara bawaan. Lihat Jaringan.

Bisakah memperbaiki tag yang salah atau sampul yang hilang?

Bisa, untuk berkas di pustakamu sendiri: menu START sebuah lagu atau album berisi Ubah tag, Tag album, Cari sampul, dan Cari di MusicBrainz, yang mengisi judul, nomor, tahun, dan genre dari MusicBrainz. Lihat Pustaka.

Beberapa lagu lebih keras dari yang lain. Apa yang bisa kulakukan?

Nyalakan Pengaturan → ReplayGain, dan untuk lagu tanpa tag ReplayGain pakai Hitung ReplayGain pada album atau artis: ia mengukurnya dan menulis tagnya. Lihat Suara.

Apakah VGM arcade bisa diputar?

Ya, di paket untuk handheld dan Linux: paket itu menyertakan libvgm, yang mengemulasi hampir semua chip di file VGM, dari papan arcade (Out Run, CPS1/2, System 16…) sampai NES, Game Boy, dan OPL. Di Windows dan iPhone, VGM diputar lewat libgme, yang hanya mengemulasi chip Mega Drive/Genesis dan Master System; di sana file lain menampilkan VGM chips not emulated alih-alih memutar senyap, dan VGMRips menyembunyikan paket tersebut.

Apakah visualisasi bereaksi terhadap tracker?

Ya. Selama tracker berputar, visualisasi, game yang mengikuti ketukan, dan latar ikut mengikuti musiknya.

Bisakah aku memakai preset MilkDrop-ku?

Bisa, preset MilkDrop 1 (.milk): taruh di folder milkdrop aplikasi (subfolder juga bisa) lalu buka visualisasi MilkDrop. Setelah menambah file, pakai START → Pindai ulang preset. Preset MilkDrop 2 bisa dimuat, tapi shader-nya diabaikan, jadi tampilannya bisa berbeda. Lihat MilkDrop. Untuk membukanya, tekan SELECT → Visualisasi lalu pakai ←/→ sampai MilkDrop (v0.12.0 atau lebih baru). Kamu bisa memilih folder lain di Pengaturan → Preset MilkDrop.

Tombolnya tidak cocok dengan huruf di konsol saya.

Nyalakan Pengaturan → Tukar A/B dan X/Y (di bagian Sistem). Ini menukar terima dan kembali, serta X dan Y, untuk konsol dengan huruf gaya Nintendo (A di kanan, X di atas). Untuk memilihnya, tekan tombol yang saat ini menerima.

Apakah mendukung buku audio?

Ya. File .m4b, file bergenre buku audio dan apa pun di folder Audiobooks diputar sebagai buku: mengingat sampai mana kamu di tiap buku, menampilkan babnya, melompat 30 detik dan mengubah kecepatan tanpa mengubah nada. Lihat Buku audio.

Bisakah membangunkanku dengan musik?

Bisa: Pengaturan → Alarm. Pilih jam, hari dan yang diputar; volume naik perlahan. Berbunyi saat pemutar tertutup dan, di konsol genggam, membangunkan konsol dari tidur, tapi tidak bila mati. Lihat Alarm.
