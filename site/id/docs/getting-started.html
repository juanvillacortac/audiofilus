Memulai

Instal audiofilus di perangkatmu, buka, lalu arahkan ke musikmu.

Handheld dengan PortMaster

Berjalan di Knulli, muOS, ROCKNIX, ArkOS, dan dArkOS.

  1. Unduh audiofilus-portmaster.zip dari rilis terbaru.
  2. Instal dengan PortMaster, atau ekstrak ke folder ports-mu.
  3. Buka audiofilus dari Ports.

Port-nya membawa semua yang dibutuhkan, termasuk pustaka yang memutar musik konsol (libgme).

muOS, tanpa PortMaster

  1. Unduh audiofilus.muxapp dari rilis terbaru.
  2. Salin ke folder ARCHIVE di root kartu SD-mu (atau flashdisk USB).
  3. Buka Archive Manager muOS dan instal. audiofilus muncul di Applications.

Desktop Linux

curl -fsSL https://juanvillacortac.github.io/audiofilus/install.sh | sh

Perintah ini menginstal audiofilus ke ~/.local/share/audiofilus, membuat tautan audiofilus di ~/.local/bin, dan menambahkannya ke peluncur aplikasimu (dengan “Buka dengan” untuk file audio dan folder). Jalankan lagi untuk memperbarui; pengaturanmu tetap.

Secara manual: ekstrak audiofilus-linux-amd64.tar.gz (atau -arm64) di mana saja lalu jalankan ./audiofilus desktop install sekali.

Windows

Di Windows 10 atau lebih baru, ekstrak audiofilus-windows-amd64.zip di mana saja lalu jalankan audiofilus.exe. MP3, FLAC, Ogg Vorbis, ALAC, WAV, dan AIFF langsung bisa diputar. Untuk AAC/M4A, Opus, dan modul tracker, taruh DLL MSYS2 di samping .exe: libfdk-aac-2.dll, libopusfile-0.dll (dengan libopus-0.dll dan libogg-0.dll), libmpg123-0.dll, dan libxmp-4.dll. Musik konsol belum tersedia di Windows.

iPhone dan iPad

Setiap rilis punya audiofilus-ios-unsigned.ipa tanpa tanda tangan. Instal dengan Sideloadly atau AltStore, yang menandatanganinya dengan Apple ID-mu sendiri.

Atau tambahkan sumber https://juanvillacortac.github.io/audiofilus/altstore.json ke AltStore, SideStore, atau LiveContainer: rilis baru muncul di sana sebagai pembaruan.

Pertama kali: folder musikmu

Di handheld atau desktop, saat pertama kali membuka audiofilus, ia menampilkan penjelajah folder. A membuka folder, B naik satu tingkat, dan X memakai folder saat ini. Pustaka dipindai sekali, dengan bilah progres; saat dibuka berikutnya hanya file baru atau yang berubah yang dibaca. Kamu bisa mengganti folder nanti di Pengaturan → Folder, dan memindai ulang dengan Pindai ulang.

Tidak punya musik sendiri? audiofilus tetap terbuka dengan pustaka kosong, jadi server, radio, podcast, dan YouTube Music tetap bisa dipakai.

Di iPhone, salin lagu ke Di iPhone Saya → Audiofilus di aplikasi File, atau pilih folder mana pun (iCloud Drive atau aplikasi lain) di Pengaturan → Folder.

Mengenal tampilannya

  • SELECT membuka bilah layar (Sedang diputar, Pustaka, Cari, Antrean, Radio, Podcast, Game, Pengaturan…). Tekan dua kali untuk kembali ke layar sebelumnya.
  • START membuka menu Lainnya di layar tempat kamu berada.
  • Tahan FN (F1 di keyboard) untuk melihat fungsi setiap tombol di layar itu.

Memperbarui

Instal rilis baru dengan cara yang sama. Pengaturanmu (audiofilus.json) dan data (data/) ada di samping program, jadi tetap aman.
