Subsonic, Navidrome, dan Jellyfin

Pakai server musik sebagai pustaka tambahan, dengan streaming, cache, favorit, dan hitungan putar.

Menambahkan server

Pengaturan → Server → Tambah server. Pilih jenisnya (Subsonic/OpenSubsonic, yang mencakup Navidrome, gonic, Airsonic, dan lainnya; atau Jellyfin/Emby), lalu masukkan nama, alamat (http://ip:port), pengguna, dan kata sandi. Koneksi dites sebelum disimpan; jika tidak menjawab, kamu bisa mencoba lagi, memperbaiki data, atau tetap menyimpannya.

Setiap server menjadi pustaka tambahan di bilah layar, dengan album, artis, lagu, playlist, dan pencarian. Katalognya disimpan, jadi langsung tampil bahkan tanpa jaringan.

Opsi per server

  • Kualitas dengar: MP3 192 kbps secara bawaan (sedikit yang diunduh, ringan untuk didekode), 320, 128, 96, atau Asli (tanpa konversi).
  • Tes koneksi, Segarkan katalog, Ubah data, Hapus server.

Streaming dan cache

Lagu disimpan di kartu SD saat diputar (400 MB secara bawaan; yang paling lama tidak dipakai dihapus duluan), dan lagu berikutnya diambil lebih dulu. Lagu yang ada di cache bisa diputar tanpa jaringan. Kamu juga bisa Unduh ke pustaka lagu dari server, lengkap dengan tag dan sampulnya, ke folder musikmu.

Favorit, rating, dan hitungan putar

  • Menyukai atau memberi rating lagu dari server juga memberi bintang atau rating di server itu. Jellyfin punya favorit tapi tidak punya rating 1 sampai 5.
  • Saat katalog server dimuat, lagu yang diberi bintang dan rating ditambahkan ke daftar Disukai-mu.
  • Lagu yang kamu dengarkan juga dihitung di server (Navidrome bisa meneruskannya ke Last.fm dan ListenBrainz jika kamu mengaturnya di sana). Matikan di Pengaturan → Scrobbling → Hitung di server.

Playlist di server bisa diputar tapi tidak bisa diedit dari audiofilus.
